# WineBank ハウススタイル

WineBankの対外資料（金融機関・株主・取締役会）は、**無彩色のミニマルデザイン**で作る。
森ビルの企業広報に近い方向性で、色数ではなく余白・線の細さ・文字の強弱で情報の階層を作る。

なぜかというと、この会社の資料は「不動産・投資・高額資産」の文脈で読まれるからだ。
彩度の高い色は説得材料にならず、むしろ軽く見える。無彩色に落とすと、数字そのものが前に出る。

## 絶対に外さない2点

**1. フォントはメイリオ（Meiryo）** — 見出しも本文も表も全部。欧文専用フォントに切り替えたり、
明朝と混植したりしない。等幅が必要な箇所だけ `Consolas` を許容する。

**2. 有彩色を使わない** — 赤・青・緑・ワインレッド等は使わない。下のパレット以外の色を足さない。

## パレット

| 用途 | HEX |
|---|---|
| 主要テキスト・濃パネル地 | `1A1A1A` |
| 中間パネル・グラフ主系列 | `333333` |
| 副次テキスト・グラフ副系列 | `595959` |
| 注記・キャプション・軸ラベル | `8C8C8C` |
| 罫線・区切り | `DCDAD6` |
| 強調行・帯のフィル | `F0EFEC` |
| ページ地 | `F7F6F3` |
| 反転文字・カード地 | `FFFFFF` |

濃淡は上から下へ連続している。強調したい要素ほど濃くする、それだけで階層は足りる。

## マイナス数値の扱い

色で区別しない。**`▲` を数値の前に付ける**（`▲23.1`）。日本の財務資料の標準表記であり、
モノクロ印刷でも伝わる。どうしても視覚的に分けたい場合のみ `595959` に落とす。

## 強調の作り方（色を使わずに）

- **濃パネル反転** — 最重要の数字ひとつを `1A1A1A` 地に白抜きで置く。1スライドに1つまで。
- **サイズ** — ヒーロー数値は36〜44pt。本文の3倍以上の差をつけると色なしでも視線が向く。
- **`F0EFEC` の帯** — 表の合計行、結論の一文。塗りは薄く、罫線は `DCDAD6` の細線。
- **余白** — 詰めない。スライドの外周は0.65インチ以上、ブロック間は0.3〜0.5インチ空ける。

## 使ってはいけないもの

- タイトル下のアクセント罫、スライド端の帯・サイドストライプ（AI生成資料の典型で、品位を落とす）
- ドロップシャドウの多用（使うなら `opacity 0.08〜0.10` の極薄まで）
- 角丸の乱用（`rectRadius` は0.05前後、もしくは直角）
- グラデーション、絵文字、装飾アイコン

## パワポで作る場合

`pptxgenjs` を使う。フォント指定は `fontFace:'メイリオ'`。
グラフは `chartColors` を `['1A1A1A','595959','8C8C8C','C4C2BE']` の順で使い、
`catAxisLabelColor` / `valAxisLabelColor` は `8C8C8C`、
`valGridLine` は `{color:'E8E6E2',size:1}`、`catGridLine` は `{style:'none'}`。

**QAの注意** — メイリオはレンダリング環境に無いことが多く、PDF化して目視確認するときは
代替フォントに置き換わる。文字幅が変わるので、テキストボックスは実測より1割ほど広くとっておく。
プレビュー上のはみ出しは実ファイルでは起きないこともあるし、その逆もある。

## Excelで作る場合

`openpyxl` の `Font(name='メイリオ')` を全セルに適用する。
表示形式は `¥#,##0;(¥#,##0);-`、入力セルは `1A1A1A` の太字、
数式セルは通常ウェイト、他シート参照は `595959`。
塗りは `F0EFEC`（合計行）と `FFFFFF`（通常）の2階調で足りる。

## 判断に迷ったら

「この要素は色がないと成立しないか？」と自問する。
成立しないなら、それは色ではなく構造の問題なので、配置か文言を直す。
