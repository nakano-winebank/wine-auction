# WineGO ターミナル設置セラー（144本 / 50SKU）ワインリスト

対象: 水商売（クラブ・ラウンジ・会員制バー）および客単価1万円以上の飲食店
セラー: 1台 = 144本（750ml 換算）
構成: 泡 20SKU / 白 10SKU / 赤 20SKU = 計 50SKU / 144本

---

## 1. 設計方針

| 方針 | 内容 |
|---|---|
| 価格帯 | 小売（ターミナル販売価格）で **〜3万 / 3〜5万 / 5〜10万 / 10〜20万** の4帯に**均等配分**。上限は20万未満 |
| 再現性 | **同一スペックで再仕入できる銘柄を優先**。大手メゾン・大手ネゴシアン・安定流通の造り手で骨格を作り、割当品は最小限に抑制 |
| 除外 | DRC は除外（指定通り）。割当制かつ相場変動が大きく、再現性・資金効率の双方で定番棚に不適 |
| 五大シャトー | **全5シャトーを収録**。20万未満に収めるためオフヴィンテージ（2014/2017等）を指定 |
| 本数配分 | 低価格帯＝回転前提で複数本、高価格帯＝指名対応で1本。平均 2.9本/SKU |

### 価格帯 × カテゴリー 配分（SKU数）

| 小売価格帯 | 泡 | 白 | 赤 | 計 |
|---|---:|---:|---:|---:|
| 〜3万円 | 6 | 3 | 4 | **13** |
| 3〜5万円 | 5 | 2 | 5 | **12** |
| 5〜10万円 | 5 | 3 | 5 | **13** |
| 10〜20万円 | 3 | 2 | 6 | **11** |
| 20万円〜（象徴枠） | 1 | 0 | 0 | **1** |
| **計** | **20** | **10** | **20** | **50** |

### 再現性の記号

- **◎** 常時流通。同スペックでいつでも再仕入可（大手メゾン・大手ネゴシアン・NV）
- **○** 流通量あり。ヴィンテージは変動するが銘柄としては継続調達可
- **△** 割当・数量限定。ヴィンテージ指定不可の場合あり。欠品時は代替銘柄で埋める前提

## 6. 運用上の注意（重要）

### 6-1. サロンを定番50に入れなかった理由

ご指定のうち**サロンのみ、2つの条件と両立しません**。

- **価格**: サロン（現行 2013）は国内小売 **40〜50万円** で、「20万円未満」の枠を大きく超える
- **再現性**: 完全な割当制で、ヴィンテージ指定どころか入荷自体が不定期。「再度購入がしやすい」の要件を満たさない

そこで**#5 デラモット ブラン・ド・ブラン**（サロンと同じル・メニル・シュル・オジェ、サロンの姉妹メゾン、小売2.8万・常時流通）を定番枠に採用しました。「サロンの弟分」として売り口上も立ちます。

**サロン本体は「指名時取り寄せ枠」として下記と同じ扱いを推奨**します（セラーには置かない）。

| 取り寄せ枠（セラー外・受注対応） | 想定小売 |
|---|---:|
| サロン ブラン ド ブラン | 450,000 |
| アルマン ド ブリニャック マグナム | 250,000 |
| ドン ペリニヨン P2 上位ヴィンテージ | 350,000〜 |
| ペトリュス / マッセート等 | 800,000〜 |

### 6-2. 五大シャトーのヴィンテージ選定について

五大シャトーは**当たり年（2015/2016/2018/2019/2020）だと小売25〜60万円**になり、価格帯を外れます。本リストでは **2014 / 2017** を指定し、全5シャトーを **13〜18万円** に収めました。

- 2017: 春霜害で生産量は減ったが、上位シャトーの品質は良好。相場が当たり年より3〜4割安い
- 2014: カベルネにとって良好な終盤。ラトゥールは蔵出しリリースのため入手経路が安定

**販売上「五大シャトー全種あります」と言い切れることの価値**を優先した設計です。当たり年指定の要望が出た場合は取り寄せ対応としてください。

### 6-3. セラーの温度帯（要確認）

144本クラスのセラーが**単一温度帯の場合、泡（6〜8℃）と赤（16〜18℃）は同居できません**。

- 現実解は **12〜14℃の単一設定＋泡は提供前に急冷**。ただし泡が47.9%を占める本構成では、営業中のオペレーションに負荷がかかります
- **デュアルゾーン機を強く推奨**します。上段=泡・白（92本）／下段=赤（52本）で、本リストの構成比とほぼ一致します
- 導入機種が単一温度帯の場合、泡の一部（回転の速い #1〜#3 の19本）を別途フリッジ運用に回す前提で、セラー側は125本に減らす調整が必要です

### 6-4. マグナム・大容量は入りません

144本の棚ピッチは 750ml 前提です。ボトルコール需要でマグナム（1500ml）を扱う場合、**棚板を外して1本あたり4〜6本分のスペース**を消費します。本リストは全て 750ml（ディケムのみ 375ml）で組んでいるため、マグナムを入れる場合は別置きしてください。

### 6-5. 補充の考え方

- **週次で補充する層（◎・帯A/B）**: #1 モエ、#2 VC、#10 ドンペリ、#31 タルボ、#35 カロン・セギュール、#40 オーパス・ワン。ここが動かないと棚は回りません
- **月次で見る層（帯C）**: 動いた分だけ都度発注
- **売れたら都度補充（帯D・象徴枠）**: 在庫は1本固定。売れた時点で同等品を手配。**ヴィンテージが変わっても構わない運用**にしておくこと（帯Dの銘柄は同一ヴィンテージの再入手が困難なため）

### 6-6. 価格について

本リストの小売価格は **2026年前半の国内市場実勢からの想定値**です。実際の仕入可否・仕入値は **WineBank 在庫および取引先見積で要確認**です。特に帯D（五大シャトー・クリスタル・グランクリュ）は相場変動が大きいため、発注前に都度確認してください。
