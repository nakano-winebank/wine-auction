## 運用上の注意

### [要判断] 価格帯の均等配分は崩れています

当初の「小売3万・5万・10万以下・10万以上20万未満で均等」は、今回の削除指示により成立しなくなりました。安価帯を落とした結果、帯Cに19SKUが集中しています。

これは指示の直接の帰結なので、そのまま反映しています。均等配分に戻す必要があれば、帯A・Bを増やす形で組み直します。

### [重要] 泡の常用帯が1SKUだけになりました

削除の結果、3万円未満の泡はボランジェ スペシャル・キュヴェ（8本）のみです。指名の入らない通常卓に出すシャンパンの選択肢が事実上1種類になります。

泡は69本から35本へ半減し、構成比も47.9%→24.3%に下がりました。水商売では泡が売上の主戦場になるため、営業上のリスクとして挙げておきます。常用帯をもう1〜2SKU戻す判断もあり得ます（例: ヴーヴ・クリコ イエローラベル、ルイ・ロデレール コレクション）。

### [選定] ジャクソンは単一畑を採りました

ジャクソンの主力は「キュヴェ No.74x」シリーズですが、国内小売が1.6万円前後で、今回削除された価格帯に入ってしまいます。そこで単一畑のアヴィーズ シャン・カン（55,000円）を採用しました。

ただし単一畑は生産量が少なく再現性は△です。継続調達を優先するならキュヴェ No.747（1.6万円・再現性○）に差し替えられますが、価格帯の方針とは矛盾します。ご判断ください。

### [構成] 五大シャトーとそのセカンド

五大シャトーは全5種を維持。当たり年だと25〜60万円になるため 2014 / 2017 のオフヴィンテージ指定で13〜18万円に収めています。

今回それに加えてセカンドワイン3種（パヴィヨン ルージュ／カリュアド ド ラフィット／ル プティ ムートン、5.5〜6.5万円）を投入しました。「マルゴー」「ラフィット」「ムートン」の名前が通りながら本体の1/3の価格で回せるため、削除された泡の売上を埋める中核になります。

### [確認] 赤の安価帯は残してあります

泡と白では「安いから削除」を適用しましたが、赤については削除のご指定が#44のみだったため、タルボ（18,000円）とケイマス（25,000円）は残置しています。

この2つが赤の回転を支える基準ボトルですが、泡・白と価格の下限を揃えるなら削除も可能です。ご指示ください。

### [要確認] セラーの温度帯

144本クラスのセラーが単一温度帯の場合、泡（6〜8℃）と赤（16〜18℃）は同居できません。

今回の改訂で赤が94本（65.3%）と主体になったため、赤に合わせた16℃前後の単一設定が現実的になりました
- 泡35本・白15本の計50本は別途フリッジ運用、またはデュアルゾーン機の上段に振る構成を推奨します

### [制約] マグナム・大容量は入りません

144本の棚ピッチは750ml前提です。マグナム（1500ml）は棚板を外して1本あたり4〜6本分のスペースを消費します。本リストは全て750ml（ディケムのみ375ml）で組んでいます。

### [運用] 補充の考え方

週次で補充 — ボランジェSC、ドンペリ、タルボ、カロン・セギュール、ランシュ バージュ、ピション、オーパス・ワン
- 月次で確認（帯C）— 動いた分だけ都度発注
- 売れたら都度補充（帯D・象徴枠）— 在庫1本固定。ヴィンテージが変わっても可とする運用にしてください

### [前提] 価格は想定値です

小売価格は2026年前半の国内市場実勢からの想定値です。実際の仕入可否・仕入値は WineBank在庫および取引先見積で要確認。特に帯D以上は相場変動が大きいため、発注前に都度ご確認ください。

WineBankの実在庫データをいただければ、実在庫ベースに引き直します。
