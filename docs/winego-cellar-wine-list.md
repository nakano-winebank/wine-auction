# WineBank セラーワインリスト

WineBank セラー在庫を wine-auction のオークションとして出品するためのワインリストです。同ディレクトリの `winego-cellar-wine-list.csv` が、管理画面の一括インポートにそのまま投入できる形式になっています。

- リスト: 29 本（赤 19 / 白 5 / スパークリング 4 / ロゼ 1 ／ 甘口白は白に含む）
- CSV: `docs/winego-cellar-wine-list.csv`（UTF-8）
- 既存のシードデータ 8 本（シャトー・マルゴー 2015、ドン・ペリニョン 2012、ロマネ・コンティ 2018、ペトリュス 2010、サッシカイア 2017、ウィスパリング・エンジェル 2022、オーパス・ワン 2019 マグナム、ハーラン・エステート 2016）とは重複しない構成にしています

> **価格について**: 開始価格は 2026 年前半の国内実勢からの**想定値**です。WineBank の実在庫・仕入値との突き合わせは未実施のため、そのデータをいただければ実在庫ベースに引き直します。

## インポート手順

1. 管理者アカウントでログインし、`/admin/import` を開く
2. 「テンプレートをダウンロード」で書式を確認できます（`GET /api/import/template` が Excel テンプレートを返します）
3. `winego-cellar-wine-list.csv` を選択してアップロード（`POST /api/import/auctions`）
4. 取り込み結果（成功件数・失敗件数・行番号付きエラー）が返ります
5. 写真は ZIP 一括アップロード（`POST /api/import/photos-zip`）で後から付与できます。ファイル名は `<auction_id>_正面.jpg` の形式です

制約は `routes/import.js` の実装どおりです。

- ファイルサイズ上限 10MB、1 回のインポートは 1000 件まで
- 読み込まれるのは**先頭シートのみ**
- 出品者（`seller_id`）はインポートを実行した管理者アカウントになります
- **CSV は UTF-8 で保存してください。** 読み込みは `codepage: 65001`（UTF-8）固定のため、Excel の「CSV (Shift_JIS)」で保存すると日本語が化けます。「CSV UTF-8」を選んでください。ヘッダ行の BOM は実装側で除去されます

## 列の仕様

| 列名 | 必須 | 内容 | 未指定時 |
|---|---|---|---|
| タイトル | ○ | オークションのタイトル | 行がスキップされます |
| 生産者 | ○ | ワイナリー・シャトー名 | 行がスキップされます |
| 開始価格 | ○ | 入札開始金額（円・整数）。0 以下は無効 | 行がスキップされます |
| 終了時間(時間) | | 掲載時間。`72` で 3 日間。0 以下は無効 | 72 |
| ヴィンテージ | | 収穫年（整数） | NULL |
| 産地 | | 例: `フランス / ボルドー` | NULL |
| アペラシオン | | 例: `Margaux AOC 1er Grand Cru` | NULL |
| 品種 | | 例: `Cab.S 87% / Merlot 8%` | NULL |
| 容量ml | | 750 / 1500 など | 750 |
| 保管状態 | | 例: `木箱未開封 / 温度管理済みセラー保管` | `未開封` |
| 説明 | | 商品説明 | NULL |
| RPスコア | | ロバート・パーカー点数 | NULL |
| WSスコア | | ワイン・スペクテイター点数 | NULL |
| ワイン種別 | | `赤` / `白` / `スパークリング` / `ロゼ` | `赤` |
| 正面画像URL | | `http` で始まる URL のみ登録されます | 登録なし |
| 背面画像URL | | 同上（ラベルは「背面（裏ラベル）」） | 登録なし |
| キャップ画像URL | | 同上（ラベルは「キャップシール」） | 登録なし |

補足:

- 列名は別名も受け付けます（`商品名` / `ワイン名` → タイトル、`色` / `種別` → ワイン種別、`AOC` → アペラシオン など。英語のカラム名 `title` / `producer` などでも可）
- ワイン種別は `red` / `rouge`、`white` / `blanc`、`sparkling` / `champagne` / `シャンパン` / `シャンパーニュ`、`rose` / `rosé` も認識します。該当しない値は `other` になります
- 絵文字とカードの配色はワイン種別から自動設定されるため、CSV に含める必要はありません
- 現在価格は開始価格と同じ値で初期化されます
- 終了日時はインポート実行時刻 + 終了時間(時間) で計算されます
