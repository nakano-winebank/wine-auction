## 方針

- **投資関連の訴求は全て削除。** ワインファンド、ワインST、エンジェル税制、Liv-ex指数、運用実績等は掲載しない。「使えるサービス」としての提案に統一。例外として、ワイン投資2.1のNOT A HOTEL的な訴求（ライフスタイル会員権としての位置づけ）のみポジショニング1枚で採用。
- **Cloud Wine Cave を核**に据えた構成。テナント飲食店に最も刺さる論点として全体像の①に配置。
- **レジデンス居住者への開放は「卸値×1.1」で提案**し、開放の是非・段階設計を明示（P.7）。
- **トンマナは会社紹介（2026年6月）準拠**：白背景／濃紺フッターバー `2F3941`／タンアクセント `C68A65`／ロゴ右上。

## 要確認事項

- **WineBank CLUBの記載は公開情報で検証済み**（[PR TIMES](https://prtimes.jp/main/html/rd/p/000000006.000115945.html)／[WINEBANK CLUB](https://corp.wine-bank.co.jp/business/winebankclub/)）。2025年7月開始の月額会員制（旧：Fine Wine Collection）、ワインは飲食店仕入れ原価相当＝通常メニュー価格の約半額、BYO無料、同伴者も同特典。「グループ飲食店20%OFF／年会費30万円／提携26店舗」は出資者特典・Founding10の数字であり誤りだったため全ページ修正。月会費は8,800円〜と記載（プラン別の詳細は要確認）。
- **館内ワインストレージ（15〜30坪）の場所提供**が最重要の要望。森ビル様が場所、当社が設備・在庫・スタッフ・在庫リスクを負担する分担で提案。テナント利用が想定に届かない場合は当社が全量活用する旨も明記済み。
- Cloud Wine Cave の配送スピードは「現状：前日午前中注文で翌日着」「館内ストレージ開設後：即日・最短5分」で全ページ統一。
- 置きワイン（消化仕入）の与信は売上入金担保を前提として記載。実際の与信条件は要設計。
- CLUBは通常（P.10）／Hills版（P.11）に分離。ワイン100本預りはCLUB標準特典から外し Program 06 に切り出し済み。
- 差別化スライド（P.19）の比較欄は競合社名を出さず「ワイン専門小売・インポーター」と表記。
- 主要ヒルズの就業者数・住戸数・テナント飲食店数は未確定のため、P.21の試算は前提値ベース。実数をいただいて精緻化する。
- P.23のPoC対象街区（麻布台ヒルズ／六本木ヒルズ）は仮置き。
- レジデンス居住者への開放（卸値×1.1〜1.3）は要ご判断。P.8に段階開放案（STEP1: CLUB会員限定 → STEP2: 全居住者 → STEP3: 贈答・催事）を記載。
- 「Bistro & Bar WineBank terrace」は施設名を出さず「六本木の路面店」と表記（本文では未掲載）。
- 累計調達額は本文では使用せず、Appendix（会社紹介p.7の原本画像）の7.5億円のみ。
