## 要確認事項

- 主要ヒルズの就業者数・住戸数は未確定のため、P.14の試算は前提値ベース（母集団・転換率は要すり合わせ）。
- P.16のPoC対象街区（麻布台ヒルズ／六本木ヒルズ）は仮置き。
- 累計調達額は「7.2億円（2026年4月末時点）」で統一。2026年6月付の会社紹介資料では7.5億円の記載があるため、最新値に更新する場合は全ページ一括で差し替えが必要。
