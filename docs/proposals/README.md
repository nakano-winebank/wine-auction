## 方針

- **投資関連の訴求は全て削除。** ワインファンド、ワインST、エンジェル税制、Liv-ex指数、運用実績等は掲載しない。「使えるサービス」としての提案に統一。例外として、ワイン投資2.1のNOT A HOTEL的な訴求（ライフスタイル会員権としての位置づけ）のみポジショニング1枚で採用。
- **Cloud Wine Cave を核**に据えた構成。テナント飲食店に最も刺さる論点として全体像の①に配置。
- **レジデンス居住者への開放は「卸値×1.1」で提案**し、開放の是非・段階設計を明示（P.7）。
- **トンマナは会社紹介（2026年6月）準拠**：白背景／濃紺フッターバー `2F3941`／タンアクセント `C68A65`／ロゴ右上。

## 要確認事項

- 主要ヒルズの就業者数・住戸数・テナント飲食店数は未確定のため、P.16の試算は前提値ベース。実数をいただいて精緻化する。
- P.18のPoC対象街区（麻布台ヒルズ／六本木ヒルズ）は仮置き。
- レジデンス居住者への開放（卸値×1.1）は要ご判断。P.7に段階開放案（STEP1: CLUB会員限定 → STEP2: 全居住者 → STEP3: 贈答・催事）を記載。
- 「Bistro & Bar WineBank terrace」は施設名を出さず「六本木の路面店」と表記（本文では未掲載）。
- 累計調達額は本文では使用せず、Appendix（会社紹介p.7の原本画像）の7.5億円のみ。
