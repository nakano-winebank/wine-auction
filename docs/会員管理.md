# 会員管理（ワイン購入後）

WineBank でワインを購入した会員の、購入後の資産・ランク・手数料・ワインマイルを扱うモジュール。
2026/8/31 中谷氏MTGの決定事項を実装の起点にしている。

| MTGでの決定 | 実装 |
|---|---|
| マイルをコミュニティ通貨として使う | `mile_transactions.channel` にレストラン・スクール・イベント・オークション等を記録 |
| 期間限定ポイントに 3〜6ヶ月の有効期限 | `mile_lots.expires_at`。種別ごとの既定は `MILE_VALIDITY_DAYS` |
| ランク別の還元率 | `member_ranks` テーブル（100万 3.5% / 400万 4.5% / 1000万 5.5%） |
| 回遊するほどマイルが貯まる | `kind='bonus'` の付与 API。行動連動マイルは 180 日で失効 |
| 上位ランクを目指したくなる見せ方 | マイ・セラーに次ランクまでの進捗バーと還元率の差分を表示 |

## 構成

```
db/membership-schema.js   スキーマ定義（PG / SQLite 両対応の DDL を1つの定義から生成）
db/helpers.js             INSERT..RETURNING の吸収、ISO日時ユーティリティ
services/members.js       会員口座・保有ワイン・時価・ランク判定・管理手数料・年次還元
services/miles.js         マイル台帳（付与ロット・FIFO消込・失効）
routes/members.js         会員向け API（/api/member）
routes/admin-members.js   管理者向け API（/api/admin/members）
public/member.html        会員向け「マイ・セラー」
public/admin-members.html 管理画面「会員管理」
test/membership.test.js   ユニットテスト（`npm test`）
```

スキーマはサーバ起動時に `migrate()` が冪等に適用する。既存の `database.js` には手を入れていない
（SQLite のファイルパスを `SQLITE_PATH` で差し替えられるようにした一行を除く）。

## データモデル

- **member_accounts** — ユーザー1人につき1つの会員口座。`rank_code` は簿価から自動算定される。
  `locked_rank_code` を入れると簿価に関わらずそのランクで固定できる（特例対応用）。
- **holdings** — 購入した1明細＝1行。`acquired_unit_price` が簿価。`status` が `stored` / `shipped`
  の間だけ資産合計に入り、`sold` / `withdrawn` になると外れる。
- **holding_valuations** — 時価の履歴。最新の `as_of` の行が評価に使われる。
- **management_fees** — 期間ごとの手数料計上。同一期間の二重計上は弾く。
- **mile_lots** — 付与のロット。有効期限と残量を持つ。
- **mile_transactions** — 監査証跡。残高の正は `mile_lots.remaining_amount` の合計。

## マイルの消込順序

有効期限が近いロットから引き当てる（FIFO by expiry）。期限なしのロットは最後に回る。
これにより、期限の近い期間限定マイルが先に消化され、失効を最小化できる。

```
付与: 還元35,000（期限365日）→ ボーナス3,000（期限180日）
利用: 5,000 → ボーナス3,000を使い切り、残り2,000を還元から
```

失効は `expireLots()` が担当し、`server.js` から1時間ごとに走る。
残高計算は期限切れロットを最初から除外するので、バッチの実行が遅れても残高が過大に出ることはない。

## 料率の変更

コード変更は不要。管理画面「会員管理 → ランク設定」で簿価下限・管理手数料率・マイル還元率を編集できる。
`PATCH /api/admin/members/ranks/:code` を叩いても同じ。

## 主な API

会員向け（要ログイン。本人の口座のみ）

| メソッド | パス | 内容 |
|---|---|---|
| GET | `/api/member` | マイ・セラー全体 |
| GET | `/api/member/holdings` | 保有ワイン |
| GET | `/api/member/portfolio` | 資産サマリとランク |
| GET | `/api/member/miles` | 残高・失効予定・明細 |
| GET | `/api/member/fees` | 管理手数料の履歴 |

管理者向け（`is_admin` 必須）

| メソッド | パス | 内容 |
|---|---|---|
| GET / POST | `/api/admin/members` | 一覧 / 口座開設 |
| GET / PATCH | `/api/admin/members/:id` | 明細 / 状態・ランク固定の変更 |
| POST | `/api/admin/members/:id/holdings` | 保有ワイン登録 |
| POST | `/api/admin/members/holdings/:hid/valuations` | 時価更新 |
| POST | `/api/admin/members/:id/fees` | 管理手数料の計上 |
| POST | `/api/admin/members/:id/miles/annual-reward` | 年次還元（簿価×ランク還元率） |
| POST | `/api/admin/members/:id/miles/grant` | 任意付与（種別・有効期限を指定可） |
| POST | `/api/admin/members/:id/miles/redeem` | 利用（消費） |
| POST | `/api/admin/members/miles/expire` | 期限切れの一括失効 |
