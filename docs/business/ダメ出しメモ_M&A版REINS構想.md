# ダメ出しメモ：「M&A版REINS」元案のレビュー

2026年10月｜社内検討用

元案（案件情報の一括閲覧＋①AI分析 ②資金調達・投資家紹介 ③代理交渉 を月額で提供、＋α ④買い手側仲介 ⑤売主の直接獲得 ⑥仲介会社へのセールス）を検討した結果です。結論として、事業概要は「指導型のAI M&A部門」に組み替えました（別紙の事業概要資料）。

## 総評

機能を足し算していて、「誰の何を解くか」がぼやけている。筋が良いのは①と④だけ。

| 要素 | 評価 | ひとこと |
|---|---|---|
| 土台：案件の一括閲覧・メルマガ | △ | MANDA・バトンズ・TRANBI等が既に無料で提供。差がつかない |
| ① AIでBS/PL×案件分析・シナジー | ○ | 一番筋が良い。ただし社名を伏せた公開情報だけでは分析が浅い |
| ② 資金調達・投資家紹介 | △ | ニーズは大きいが、法令上の登録が要るかの整理が必須 |
| ③ 仲介との代理交渉 | × | 定額では工数が青天井。法的な論点と、仲介側に拒否されるリスク |
| ④ 自社で買い手側仲介 | ○ | 収益の柱になる。③と統合して「買い手FA」に |
| ⑤ 売主を直接押さえる | × | 両手仲介になり、MANDAが批判した利益相反を自ら作る |
| ⑥ 仲介会社へのセールス | △ | 何を売るか未定義。⑤とは両立しない |

## 6つの論点

1. **「M&A版REINS」とは呼べない。** REINSは宅建業法で専任媒介の物件登録が義務で、成約価格のデータも貯まる。M&Aにはどちらもない。案件の自動収集はMANDAが2018年から実施済みで、掲載元の利用規約違反やブロックのリスクもある。
2. **社名を伏せた公開情報（ノンネーム）ではAI分析が浅い。** 業種・地域・売上の幅程度しかない。AIが本当に効くのは、秘密保持契約の後に企業概要書（IM）や決算書が出てきてから。
3. **月額定額×代理交渉は、使われるほど赤字。** 買収は数年に1回の出来事で、決まっても決まらなくても解約される。交渉は人が付きっきりの仕事で、定額では採算が合わない。
4. **法律の論点（要・弁護士確認）。**
   - 投資家紹介（出資）：金融商品取引法
   - 融資の紹介：貸金業法・銀行法
   - 代理交渉：弁護士法72条（弁護士以外が報酬目当てで法律事務をすることの禁止）
   - 案件情報の収集：各サイトの利用規約・著作権・不正競争防止法
   - 業界ルール：中小M&Aガイドライン、M&A支援機関登録制度
   - 顧客の財務データ：機密管理、AI学習への不使用
5. **④⑤⑥は同時に成り立たない。** ⑤で売り手、④で買い手につけば両手仲介。⑤をやれば仲介会社と競合になり、⑥の売り込み先を失う。
6. **MANDAの教訓：情報を集めるだけでは儲からない。** 月1.3万人が使っても、主な収益はバナー広告の月33万円。課金の対象を「情報」から「買収の成功」に移す必要がある。
