# 中野スタイル（いつものトンマナ）

参照元：「MA講演_NIB第56回月例会20260927.pptx」（2026年10月の講演資料）。この見た目を再現する。

## 使い方

1. まず `pptx` スキルを読む（pptxgenjs の注意点・QA手順はそちらに従う）。
2. ビルドスクリプトから `scripts/style.js` を読み込み、レイアウト・部品はすべてここから使う。

```js
const pptxgen = require("pptxgenjs");
const S = require("<このスキルのディレクトリ>/scripts/style.js");
const pres = new pptxgen();
const k = S.setup(pres, { footer: "Confidential", pptxSkill: "<pptxスキルのディレクトリ>" });
let s = k.cover({ kicker: "イベント名 ／ 日付", title: "タイトル", sub: "〜 サブタイトル 〜", name: "中野 邦人", role: "株式会社WineBank 代表取締役" });
s = k.content({ kicker: "OVERVIEW", title: "見出し（結論を一文で）", sub: "補足の一行" });
k.stat(s, 0.75, 2.4, 2.95, 2.14, "25.2", "億円", "支払った買収総額");
k.bar(s, 5.0, "結論を白太字で", "補足を小さく");
s = k.dark({ kicker: "C L O S I N G", title: "締めのメッセージ", body: "本文", name: "中野 邦人 ／ 株式会社WineBank" });
await k.write("deck.pptx"); // テーマ色とメイリオ（東アジア）を書き込む
```

NODE_PATH に pptxgenjs のある node_modules を指定して実行する。

## デザイントークン

| 役割 | 色 | 用途 |
|---|---|---|
| エスプレッソ | `2B2622` | 表紙・締め・結論バーの面、本文・見出しの文字 |
| 黒茶 | `1C1714` | 暗い面の右上の大きな円 |
| ブロンズ | `A78450` | キッカー、大きな数字、丸数字バッジ、短い罫 |
| 淡ブロンズ | `C9AE7E` | 暗い面の上のキッカー・強調 |
| グレージュ | `6F665F` | サブタイトル・説明文 |
| クリーム | `F5EFE4` | カードの面 |
| カード枠 | `E6DCCB` | カードの細い枠線 |
| 暗いカード | `3A322C`／枠`4E443C` | 暗い面の上のカード |
| 強調の青 | `0070C0` | 本文中で一番伝えたい数字だけ（太字＋青、`k.EM`） |

- フォント：見出し・本文ともメイリオ（Meiryo）。
- 画面：16:9 ワイド（13.333×7.5インチ）、左右余白0.75インチ。
- 文字サイズ：キッカー12pt（字間を広げた英字の大文字、ブロンズ）、見出し30pt太字、サブ13.5pt、本文12〜14pt、注記9〜10.5pt。

## 修正の進め方

- ユーザーがPowerPointで直したファイルが届いたら、それを正本にする。差分（文字の大きさ・太字・色・数字・図形の削除）を読み取り、生成スクリプトとこのスキルの両方に反映してから次の修正に入る。

## 構成の型

- **表紙**：暗い面＋右上の円。キッカー（イベント名・日付）→ 大見出し → 〜サブ〜 → 短いブロンズ罫 → 氏名・肩書。
- **本文スライド**：左上に「● KICKER」→ 見出しは結論の一文 → サブ一行。中身はクリーム色のカード（数字カード、丸数字のリスト、比較表）。
- **結論バー**：スライド下部にエスプレッソの帯で「言いたいこと」を白太字、補足を小さく。
- **締めの一文**：最下部にブロンズの斜体で添える（`k.note`）。
- **締め・章扉**：暗い面。字間を広げたキッカー（例：`C L O S I N G`）。
- 話す内容はスピーカーノートに入れる（`slide.addNotes`）。

## やること・やらないこと

- 数字は大きく、ブロンズで。単位は数字の下に小さく。数字カードに短いブロンズ罫は付けない。
- 強弱はメリハリ重視：説明文の中で一番伝えたい数字（例：「14.9億円が戻った」）だけを太字＋青（`0070C0`）にする。リストの見出しも全部太字にせず、強調したい行だけ太字にする。
- 勝ちと負けを両方、金額で正直に出す（このスタイルの信頼の源）。
- 外部に出す資料では案件名・相手先を匿名化する（例：「飲食A社」）。
- 青は上の「強調の青」以外に使わない。原色は使わない。色は上の表の範囲に収める。
- カードの片側だけの色帯やタイトル下の下線は使わない（短いブロンズ罫は表紙だけ）。
