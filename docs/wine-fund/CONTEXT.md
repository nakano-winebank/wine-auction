## 絶対に間違えてはいけない前提

### 「折半」の意味

**投資家が得た利益をWineBankと折半する成功報酬**のこと。SPC全体の利益を50:50で割ることでは
ない。過去に一度この解釈を誤り、利回りを35.0%と誤記して指摘を受けている。

```
山本案： SPC税前利益 × 3/5（出資3億÷総額5億） × 50% ÷ 出資3億 = 21.0%
倉持案： SPC税前利益 × 5/5                     × 50% ÷ 出資5億 = 21.0%
```

WineBankは**3億円の投資家に対しても成功報酬を取る**。「成功報酬を取らない」と書いてはならない。
課さないのは残高比例の**期中管理報酬**のみ。

### 20%の分岐点に余裕がない

主線（回転12ヶ月）で21.0%。**20%を割るのは回転12.7ヶ月**であり、余裕は0.7ヶ月しかない。
回転12ヶ月の達成は「上振れ条件」ではなく**必要条件**。15ヶ月なら17.3%、18ヶ月なら14.9%で
先方基準を下回る。この点は感応度・比較・まとめの各ページに明記済みで、後退させないこと。

ワイン価格の年6%上昇も同様に前提条件（外すと17.0%）であり、「上乗せ」ではない。

### 販売実力とのギャップ

回転12ヶ月には年間7.48億円の販売が必要。WineBankの現状の販売実力は年5〜7億円で、
10億円は困難。この差を埋める主たる手段は**組入銘柄の選定**（流動性の高い銘柄をSPCに入れる）。

### 在庫配分の公平性

WineBank自己勘定在庫との配分は**在庫比率によるプロラタが原則**。プロラタで決し得ない部分に
ついてのみSPC優先。「SPC在庫を完売するまで自己勘定を売らない」という運用は、銘柄ごとに
商品構成が異なるため実務上成立しない。契約別紙1に明文化済み。

## 品質確認の手順

PPTX/DOCX を書き出したら必ずレンダリングして目視確認する。LibreOffice の行高は指定値より
広がることがあり、表がカードや脚注を突き抜ける事故が繰り返し起きている。

```bash
soffice --headless --convert-to pdf --outdir qa foo.pptx
pdftoppm -png -r 78 qa/foo.pdf qa/s      # 各ページを画像化して確認
```
