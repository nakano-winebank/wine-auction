# ワインファンド（SPC）組成提案 — 収益モデルと提案資料

投資枠5億円・運用期間5年のワインファンド（GK-TK）について、投資家リターンを試算し
提案資料を生成する一式。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `model.py` | 単位経済・定常年間実力値・月次キャッシュフローの本体モデル |
| `report.py` | 感応度分析、保管料の実務水準チェック、チャネル別手取り比較 |
| `build.js` | 提案資料（PPTX）の生成スクリプト（pptxgenjs） |
| `WineBank_ワインファンドSPC組成提案_5億_20260811.pptx` | 生成物（全19枚） |

## 実行

```bash
python3 model.py    # 単位経済・定常年間実力値・通算リターン
python3 report.py   # 感応度・実務水準チェック
npm install pptxgenjs && node build.js   # PPTX生成
```

## 提示指標について

**提案資料ではIRRを一切使わない。** 先方（資産管理会社）が用いている尺度が「想定利回り」
であるため、以下の2つに統一している。

- **定常年間利回り** … 運用が軌道に乗った後の年間実力値（投資家配当 ÷ 出資額）
- **年平均利回り（5年通算）** … 運用期間中の累計分配額 ÷ 出資額 ÷ 年数

## モデルの前提

### ファンド設計

- 投資枠5億円、**運用期間5年**
- **出資金の95%をワイン購入に充当（現金5%）**
- 中途解約は**3年経過後、年度ごと**。当初3年間はロックアップ
- 報告は**四半期**（在庫明細・簿価・売上・試算表）／年次：決算
- 仕入展開6ヶ月、ローリング運用、利益は複利再投資せず半期分配
- SPCの税前利益を投資家50：WineBank50で折半。利回りは投資家の税引前ベース

### ワイン価格の上昇（`APPRECIATION`）

収益は二階建て。**フロー（流通価格差）＋ ストック（値上がり）** で構成される。

保有期間中に価格帯全体（希望小売・ネット最安・卸値）が連動して上昇するため、
取得原価は据え置きのまま売値だけが `(1+6%)^(保有月数/12)` 倍になる。

**値上がりの上乗せ幅は回転期間によらず年約4.0ポイントで一定。** 値上がりは在庫金額
（ストック）に対して発生し、価格差は回転（フロー）に対して発生するため、両者は独立に
足し合わさる。回転低下を「相殺」するのではなく、全体を「底上げ」する性質のもの。

| 回転期間 | ① 価格差のみ（0%） | ② 値上がりの上乗せ | 定常年間利回り |
| --- | --- | --- | --- |
| 9ヶ月 | 23.3% | +3.9pt | 27.2% |
| 12ヶ月 | 17.1% | +4.0pt | 21.1% |
| 15ヶ月 | 13.4% | +4.0pt | 17.4% |
| 18ヶ月 | 11.0% | +4.0pt | 15.0% |

上昇率6%は、会社資料のFine Wine年率10%に対し保守的に置いたもの。0%（横ばい）でも
回転12ヶ月で17.1%を確保できるため、値上がりは前提ではなく上乗せとして位置づける。

### 販売チャネル（`RATE_B2B` / `RATE_B2C`）

売値だけでなく手数料構造が異なるため、チャネルを分けて持たせている。

| | 売値（定価比） | 変動販売費 | 手取り |
| --- | --- | --- | --- |
| B2B 酒販店卸 | 70 | 1.0%（出庫・配送0.6％＋決済・与信0.4%） | 69.30 |
| B2C 自社EC・オークション | 80 | 11.2%（モール・出品5.5%＋カード決済3.2%＋出庫・梱包・クール便2.5%） | 71.04 |
| **加重平均（半々・主線）** | **75** | **6.44%** | **70.17** |

手数料が重くてもB2Cのほうが手取りは1.74高い。ただしB2Cは1本ずつの出荷で販売量に
上限があるため、回転期間を確保するにはB2Bの卸売が不可欠。

### 共通費用

| 項目 | 単価・料率 | 備考 |
| --- | --- | --- |
| 保管（定温倉庫） | 年7,500円／ロット | 1ロット＝定価100万円相当（約40本）。月約16円／本で業務用パレット定温保管の一般水準（月10〜20円／本）。個人向けセラー預かり（月100〜150円／本）とは別の料金帯 |
| 動産総合保険 | 平均在庫簿価の年0.15% | 全量付保。**滞留・破損ロスは保険でカバーするため費用計上しない** |
| 入庫・検品 | 320円／ロット | 出庫費用はチャネル別の変動販売費に含む |
| SPC維持費 | 年200万円 | 税務・事務受託・法務。**監査費用を除く** |
| SPC人件費 | 年360万円 | SPC運営に係るWineBank側の実務人件費 |

### 現物譲渡マージン（`MARKUP`）

酒類販売業免許と取引口座の制約により、WineBankが調達した現物をSPCへ譲渡する必要がある。
独立企業間価格として1%を付加。SPCの取得原価は定価比50.0→50.5。払込5億に対し
実商品原価4.95億＋譲渡マージン500万円。

## 主要な結果（ニュートラル・上昇6%）

| 在庫回転期間 | 定常年間利回り | 年平均利回り（5年通算） |
| --- | --- | --- |
| 9ヶ月 | 27.2% | 24.4% |
| 12ヶ月（主線） | 21.1% | 16.8% |
| 15ヶ月 | 17.4% | 13.0% |
| 18ヶ月 | 15.0% | 13.4% |

リターンの主たる決定要因は在庫回転期間。改善の打ち手は「回転期間の短縮」と
「調達構成の改善」の2つに集約され、値引きによる販売促進は割に合わない。

インポーターの仕入価格が上昇する局面では希望小売価格も連動して上昇するため、
定価比の構造（仕入50・売却70／80）は維持され、利回りへの影響は生じない。

先方の投資基準である想定利回り20%は、主線の回転12ヶ月（21.1%）で上回る。
20%を割り込むのは回転が**12.8ヶ月**を超えたときで、ここが交渉上の分岐点。
運用KPIとして四半期報告する設計としている。
