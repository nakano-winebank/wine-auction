# ワインファンド（SPC）組成提案 — 収益モデルと提案資料

実物ワインの流通価格差を収益源とするワインファンド（GK-TK）について、投資家リターンを
試算し提案資料を生成する一式。

## 2つの案

| | 倉持案 | 山本案（現物出資型） |
| --- | --- | --- |
| 資本構成 | エクイティ5億円のみ（デットなし） | WineBank現物出資60% ＋ 投資家出資40% |
| 募集総額 | 5億円 | ファーストクローズ5億円 → 年度内セカンドクローズ10億円 |
| 投資家のリスク資本 | 5億円 | 2億円（1stクローズ）／4億円（2ndクローズ） |
| WineBankの拠出 | なし | ワイン現物3億円（1st）／6億円（2nd） |
| 報酬 | 折半（成功報酬）のみ | 折半（成功報酬）＋ 管理報酬 年2% |
| **投資家利回り（定常年間）** | **21.0%** | **20.4%（1st）／20.5%（2nd）** |
| 20%の分岐点 | 回転12.7ヶ月 | 回転12.2ヶ月（1st）／12.3ヶ月（2nd） |

山本案は2026年8月の協議を経て、デット型（デット2億円＋エクイティ3億円）から現物出資型へ
変更した。変更内容は `changes.js` が生成する変更点資料に整理してある。

## 実行

```bash
python3 model.py      # 単位経済・定常年間実力値・通算リターン
python3 report.py     # 感応度・実務水準チェック
python3 leverage.py   # 費用積み増しとデット比率の感応度
python3 structure.py  # 山本案（現物出資型）＋ figures.json 出力
python3 kuramochi.py  # 倉持案（エクイティ5億のみ）

npm install pptxgenjs docx
node build.js            # 山本案の提案資料（PPTX）※先に structure.py を実行すること
node changes.js          # 山本案の変更点資料（DOCX）※同上
node build_kuramochi.js  # 倉持案の提案資料（PPTX）
node annex.js            # 契約別紙ドラフト（DOCX）
```

**`build.js` と `changes.js` は `figures.json` を読む。** 数値を資料に手打ちしないための構成
なので、前提を変えたら必ず `python3 structure.py` を実行してから資料を生成すること。

## 提示指標について

**提案資料ではIRRを一切使わない。** 先方（資産管理会社）が用いている尺度が「想定利回り」
であるため、以下の2つに統一している。

- **投資家利回り（定常年間）** … 投資家の取分 ÷ 投資家出資額
- **年平均利回り（5年通算）** … 運用期間中の累計分配額 ÷ 投資家出資額 ÷ 5年

### 折半の定義（もっとも重要な前提）

**折半とは「投資家が得た利益をWineBankと折半する成功報酬」のこと。** SPC全体の利益を
50:50で割るという意味ではない。定義は案の変更を通じて一貫している。

| 段階 | 計算 | 1stクローズ・回転12ヶ月 |
| --- | --- | --- |
| SPC税前利益 | 総額5億円の運用から生じる利益（管理報酬控除後） | 2.04億円 |
| ① 投資家帰属分 | × 投資家出資2億円 ÷ 総額5億円 ＝ **40%** | 81百万円 |
| ② 投資家取分 | × **50%**（残り50%はWineBankの成功報酬） | 41百万円 |
| **投資家利回り** | 41百万円 ÷ 出資2億円 | **20.4%** |

したがって投資家の取り分は SPC税前利益の **20%**（＝ 40% × 50%）である。

```
山本案（現物出資型）： SPC税前利益 × 40%（出資2億÷総額5億） × 50% ÷ 出資2億
倉持案：               SPC税前利益 × 100%                    × 50% ÷ 出資5億
```

WineBankは**投資家に対して成功報酬を取る**。「成功報酬を取らない」と書いてはならない。

### 粗利率と利回りの関係（混同しやすい点）

| | 値 | 分母 |
| --- | --- | --- |
| 単位粗利（定価100あたり・保有12ヶ月） | 23.88 | — |
| 粗利率（売上比） | 30.0% | 売却時の売値 79.50 |
| **投下原価利益率** | **47.3%** | **投下資本＝SPC取得原価 50.50** |

**利回りの源泉は投下原価利益率のほう。** 原価50.50で仕入れて手取り74.38で回収するため、
年1回転すれば投下資本が年47.3%増える。粗利は**変動販売費控除後**で統一する。

## モデルの前提

### 資本構成（`structure.py`）

**WineBank現物出資60% ＋ 投資家出資40%。** デットは廃止した。

- WineBankは自己勘定のワイン現物を拠出して総額の60%を出資する（現金拠出ではない）
- 投資家は現金で総額の40%を出資する（1口5,000万円以上）
- SPC税前利益のうち投資家出資分に帰属する40%を投資家とWineBankで**折半**
- WineBank出資分に帰属する60%は、出資者であるWineBankがそのまま受け取る
- 管理報酬として**総額の年2%**をSPC費用に計上する。従来のSPC人件費360万円はこれに置換
- 段階クローズ：ファーストクローズ5億円 → 年度内セカンドクローズ10億円

1stクローズ・回転12ヶ月・SPC税前利益2.04億円の内訳：

| | 金額 | 備考 |
| --- | --- | --- |
| 投資家帰属分（40%） | 81百万円 | |
| ├ 投資家 | **41百万円** | 出資2億円に対し **20.4%** |
| └ WineBank | 41百万円 | 成功報酬 |
| WineBank出資分帰属（60%） | 122百万円 | 現物出資3億円に対する持分 |
| 管理報酬 | 10百万円 | 総額の年2% |
| **WineBank受取合計** | **173百万円** | 持分122 ＋ 成功報酬41 ＋ 管理報酬10 |

**管理報酬は全額をWineBankが受領するが、その60%はWineBank自身の出資分に対応する自己
負担分の還流である。** さらに投資家帰属分は折半されるため、管理報酬を課さない場合と比べた
WineBankの純増は年2百万円（1stクローズ）にとどまる。一方で投資家利回りは21.4%→20.4%と
1.0ポイント低下する。

### 現物出資するワインの評価方法（未確定）

取得原価にどれだけ付加するかは**組成時の別途協議事項**であり、確定していない。本試算では
SPC取得原価を定価比50.50（市中原価50.00＋現物譲渡1%）に置いている。`model.py` の `MARKUP`
を変更すれば全数値が追随する。

参考として、付加率を上げてもWineBankの取り分はほとんど増えない。自ら60%を保有している
ため、取得原価を上げると自己の持分利益も同額減るためである（総額10億・回転12ヶ月）。

| 付加率 | 投資家利回り | WineBank受取合計 |
| --- | --- | --- |
| 原価そのまま | 20.9% | 343百万円 |
| 年6% | 18.5% | 338百万円 |
| 年10% | 17.0% | 334百万円 |

**付加率を上げると投資家の利回りだけが落ちる。** 拠出価格を吊り上げる経済的動機が構造的に
生じない点は、現物出資型の最大の利点であり、そのまま説明材料になる。

### ファンド設計

- ファーストクローズ5億円 → 年度内セカンドクローズ10億円、**運用期間5年**
- **出資金の95%をワイン購入に充当（現金5%）**
- 中途解約は**3年経過後、年度ごと**。当初3年間はロックアップ
- 適格機関投資家等特例業務による私募。AUP（合意された手続）を年次で実施
- 在庫配分は在庫比率によるプロラタを原則とし、プロラタで決し得ない部分はSPC優先
- 報告は**四半期**（在庫明細・簿価・売上・試算表）／年次：決算
- 仕入展開6ヶ月、ローリング運用、利益は複利再投資せず**年1回分配**
- 利回りは投資家の税引前ベース

### ワイン価格の上昇（`APPRECIATION`）

収益は二階建て。**フロー（流通価格差）＋ ストック（値上がり）** で構成される。

保有期間中に価格帯全体（希望小売・ネット最安・卸値）が連動して上昇するため、
取得原価は据え置きのまま売値だけが `(1+6%)^(保有月数/12)` 倍になる。

**値上がりの上乗せ幅は回転期間によらず年約4.0ポイントで一定。**

| 回転期間 | ① 価格差のみ（0%） | ② 値上がりの上乗せ | 投資家利回り |
| --- | --- | --- | --- |
| 9ヶ月 | 22.6% | +3.9pt | 26.5% |
| **12ヶ月（主線）** | 16.4% | +4.0pt | **20.4%** |
| 15ヶ月 | 12.7% | +4.0pt | 16.7% |
| 18ヶ月 | 10.2% | +4.0pt | 14.3% |

上昇率6%は、会社資料のFine Wine年率10%に対し保守的に置いたもの。ただし0%（横ばい）だと
主線でも16.4%となり20%を割る。**値上がりの織り込みは20%達成の前提条件**である。

### 販売チャネル（`RATE_B2B` / `RATE_B2C`）

| | 売値（定価比） | 変動販売費 | 手取り |
| --- | --- | --- | --- |
| B2B 酒販店卸 | 70 | 1.0%（出庫・配送0.6％＋決済・与信0.4%） | 69.30 |
| B2C 自社EC・オークション | 80 | 11.2%（モール・出品5.5%＋カード決済3.2%＋出庫・梱包・クール便2.5%） | 71.04 |
| **加重平均（半々・主線）** | **75** | **6.44%** | **70.17** |

手数料が重くてもB2Cのほうが手取りは1.74高い。ただしB2Cは1本ずつの出荷で販売量に上限が
あるため、回転期間を確保するにはB2Bの卸売が不可欠。

### 共通費用

| 項目 | 単価・料率 | 備考 |
| --- | --- | --- |
| 保管（定温倉庫） | 年7,500円／ロット | 1ロット＝定価100万円相当（約40本）。月約16円／本で業務用パレット定温保管の一般水準 |
| 動産総合保険 | 平均在庫簿価の年0.15% | 全量付保。**滞留・破損ロスは保険でカバーするため費用計上しない** |
| 入庫・検品 | 320円／ロット | 出庫費用はチャネル別の変動販売費に含む |
| SPC維持費 | 年200万円 | 税務・事務受託・法務 |
| **管理報酬** | **総額の年2%** | 1stクローズで年1,000万円、2ndクローズで年2,000万円。従来のSPC人件費360万円に代えて計上 |
| AUP | 年50万円 | 合意された手続の実施と報告書の発行 |
| 予備費 | 年50万円 | 想定外の実費に充当 |

### 現物譲渡マージン（`MARKUP`）

酒類販売業免許と取引口座の制約により、WineBankが調達した現物をSPCへ譲渡する必要がある。
独立企業間価格として1%を付加。SPCの取得原価は定価比50.0→50.5。

## 主要な結果（ニュートラル・上昇6%・ファーストクローズ5億円）

**在庫回転12ヶ月が主線。** 最短9ヶ月、延びても15〜18ヶ月を想定レンジとする。
回転12ヶ月には年間7.48億円の販売が必要で、現状の販売実力（5〜7億円）の上限をやや上回る。

| 在庫回転期間 | 必要な年間販売額 | SPC税前利益 | 投資家帰属分（40%） | 投資家取分（折半後） | 投資家利回り | 年平均利回り（5年通算） |
| --- | --- | --- | --- | --- | --- | --- |
| 9ヶ月（最短） | 9.83億円 | 2.65億円 | 106百万円 | 53百万円 | 26.5% | 23.7% |
| **12ヶ月（主線）** | 7.48億円 | 2.04億円 | 81百万円 | 41百万円 | **20.4%** | 16.0% |
| 15ヶ月 | 6.07億円 | 1.67億円 | 67百万円 | 33百万円 | 16.7% | 12.2% |
| 18ヶ月 | 5.13億円 | 1.43億円 | 57百万円 | 29百万円 | 14.3% | 12.7% |

セカンドクローズ（10億円）は比率が同じため利回りもほぼ同じで、回転12ヶ月で20.5%・
5年通算16.2%となる。ただし**必要な年間販売額は7.48億円→14.96億円へ倍増する。**
現状の販売実力（年5〜7億円）の2倍を超えるため、セカンドクローズは販売実力の拡大と
セットで判断する。

> 5年通算の年平均利回りは、回転15ヶ月（12.2%）より回転18ヶ月（12.7%）のほうが高い。
> 5年のあいだに何回転収まるかによる段差であり、両者とも実現回転は3.0回である一方、
> 18ヶ月のほうが1回転あたりの値上がりが大きいために生じる。また `model.monthly` は
> 満期時の残存在庫を簿価で戻す保守的な計算としているため、回転15ヶ月では完了間近の
> 回転に含まれる利益が計上されない。満期時の売却清算条件とあわせて整理が必要。

### 20%の分岐点

| 前提 | 20%を割る回転期間 | 主線12ヶ月からの余裕 |
| --- | --- | --- |
| ニュートラル（上昇6%） | **12.2ヶ月** | **0.2ヶ月** |
| 上昇0%（横ばい） | 10.0ヶ月 | 余裕なし（主線で16.4%） |
| ネガティブ（値引き5%＋横ばい） | 8.2ヶ月 | 余裕なし（主線で13.1%） |

**回転12ヶ月の達成は「上振れ条件」ではなく20%確保の必要条件。** 余裕は0.2ヶ月しかない。
管理報酬 年2% を新設したことで、デット型時点の0.7ヶ月からさらに縮まっている。これが本
ファンド最大の管理項目であり、組入銘柄を流動性上位に絞ることと、B2B卸とB2Cを併走させて
販売量を確保することが設計の中心になる。

### 感応度（主線20.4%を基準・1stクローズ）

| 変動要因 | 変動幅 | 投資家利回り | 影響 |
| --- | --- | --- | --- |
| 在庫回転期間 | 12ヶ月 → 18ヶ月 | 14.3% | ▲6.1pt |
| ワイン価格上昇率 | 年6% → 0% | 16.4% | ▲4.0pt |
| 売却価格 | 売値 ▲5% | 16.9% | ▲3.5pt |
| 稼働率 | 95% → 85% | 18.1% | ▲2.3pt |
| B2Cのモール手数料 | 5.5% → 8.0% | 19.4% | ▲1.0pt |
| ワイン価格上昇率 | 年6% → 10% | 23.0% | ＋2.6pt |
| 調達構成 | 定価比 50 → 45 | 28.0% | ＋7.7pt |

**利回りを作るために費用を圧縮する必要はない。** インポーターの仕入価格が上昇する局面では
希望小売価格も連動して上昇するため、定価比の構造は維持され、利回りへの影響は生じない。

## 山本案の変更の経緯（回転12ヶ月）

| | 前提 | 投資家利回り |
| --- | --- | --- |
| ① | 旧版：投資家5億円出資・折半・値上がり未計上 | 17.0% |
| ② | ワイン価格の年6%上昇を織り込む | 21.0% |
| ③ | デット2億円を導入し、出資を3億円に | 21.0% |
| ④ | デットを廃止し、WineBank現物出資60%へ | 21.4% |
| ⑤ | 管理報酬 年2% を新設 | **20.4%** |

折半の定義は①〜⑤を通じて一貫して変更していない。③でデットを導入しても利回りが変わら
なかったのは、出資が5億円→3億円になる一方で帰属利益も5分の3になったためである。④で
デットを廃止したぶんSPC人件費360万円が不要になり、⑤の管理報酬でその分を上回る費用を
計上したため、差引きで20.4%となっている。
