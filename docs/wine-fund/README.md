# ワインファンド（SPC）組成提案 — 収益モデルと提案資料

投資枠5億円・運用期間5年のワインファンド（GK-TK）について、投資家リターンを試算し
提案資料を生成する一式。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `model.py` | 単位経済・定常年間実力値・月次キャッシュフローの本体モデル |
| `report.py` | 感応度分析、保管料の実務水準チェック、チャネル別手取り比較 |
| `leverage.py` | 費用積み増しの影響、デット比率別の感応度 |
| `structure.py` | デット2億＋エクイティ3億の資本構成での投資家リターン（**本番用の数値はこれ**） |
| `build.js` | 提案資料（PPTX）の生成スクリプト（pptxgenjs） |
| `WineBank_ワインファンドSPC組成提案_5億_20260811.pptx` | 生成物（全23枚） |

## 実行

```bash
python3 model.py    # 単位経済・定常年間実力値・通算リターン
python3 report.py   # 感応度・実務水準チェック
python3 leverage.py # 費用積み増しとデット比率の感応度
python3 structure.py # 資本構成込みの投資家リターン（本番用）
npm install pptxgenjs && node build.js   # PPTX生成
```

## 提示指標について

**提案資料ではIRRを一切使わない。** 先方（資産管理会社）が用いている尺度が「想定利回り」
であるため、以下の2つに統一している。

- **定常年間利回り** … 運用が軌道に乗った後の年間実力値（投資家配当 ÷ 出資額）
- **年平均利回り（5年通算）** … 運用期間中の累計分配額 ÷ 出資額 ÷ 年数

## モデルの前提

### 資本構成（`structure.py`）

総額5億円 ＝ **デット2億円（金利4%）＋ エクイティ3億円**。

- デット2億円の調達コストはWineBankが負担し、SPCの費用には計上しない
- その見返りにWineBankはエクイティ2億円相当としてカウントされる
- SPCの税前利益は出資比率で按分：**投資家60 : WineBank40**
- 投資家の元本3億円は満期に償還（デット2億円はSPC資産から返済）

投資家の出資比率（3億÷5億＝60%）と損益の配分比率（60%）が一致しているため、
エクイティ利回りはSPCの資産利回りそのものとなる。レバレッジによる上振れはWineBankの
取り分（無拠出で40%）とデットの金利負担で相殺されている。

同一投資家がデットとエクイティの双方を拠出する場合、5億円全体に対する合成利回りは
27.2%（回転12ヶ月）。

### ファンド設計

- 総額5億円、**運用期間5年**
- **出資金の95%をワイン購入に充当（現金5%）**
- 中途解約は**3年経過後、年度ごと**。当初3年間はロックアップ
- 適格機関投資家等特例業務による私募。AUP（合意された手続）を年次で実施
- 報告は**四半期**（在庫明細・簿価・売上・試算表）／年次：決算
- 仕入展開6ヶ月、ローリング運用、利益は複利再投資せず半期分配
- 利回りは投資家の税引前ベース

### ワイン価格の上昇（`APPRECIATION`）

収益は二階建て。**フロー（流通価格差）＋ ストック（値上がり）** で構成される。

保有期間中に価格帯全体（希望小売・ネット最安・卸値）が連動して上昇するため、
取得原価は据え置きのまま売値だけが `(1+6%)^(保有月数/12)` 倍になる。

**値上がりの上乗せ幅は回転期間によらず年約8.0ポイントで一定**（エクイティ3億円ベース）。
値上がりは在庫金額（ストック）に対して発生し、価格差は回転（フロー）に対して発生する
ため、両者は独立に足し合わさる。回転低下を「相殺」するのではなく、全体を「底上げ」する。

| 回転期間 | ① 価格差のみ（0%） | ② 値上がりの上乗せ | エクイティ利回り |
| --- | --- | --- | --- |
| 9ヶ月 | 46.4% | +7.9pt | 54.2% |
| **12ヶ月（主線）** | 34.1% | +7.9pt | **42.0%** |
| 15ヶ月 | 26.7% | +8.0pt | 34.7% |
| 18ヶ月 | 21.8% | +8.0pt | 29.8% |

上昇率6%は、会社資料のFine Wine年率10%に対し保守的に置いたもの。0%（横ばい）でも
主線でエクイティ利回り34.1%を確保できるため、値上がりは前提ではなく上乗せとして
位置づける。

### 販売チャネル（`RATE_B2B` / `RATE_B2C`）

売値だけでなく手数料構造が異なるため、チャネルを分けて持たせている。

| | 売値（定価比） | 変動販売費 | 手取り |
| --- | --- | --- | --- |
| B2B 酒販店卸 | 70 | 1.0%（出庫・配送0.6％＋決済・与信0.4%） | 69.30 |
| B2C 自社EC・オークション | 80 | 11.2%（モール・出品5.5%＋カード決済3.2%＋出庫・梱包・クール便2.5%） | 71.04 |
| **加重平均（半々・主線）** | **75** | **6.44%** | **70.17** |

手数料が重くてもB2Cのほうが手取りは1.74高い。ただしB2Cは1本ずつの出荷で販売量に
上限があるため、回転期間を確保するにはB2Bの卸売が不可欠。

### 共通費用

| 項目 | 単価・料率 | 備考 |
| --- | --- | --- |
| 保管（定温倉庫） | 年7,500円／ロット | 1ロット＝定価100万円相当（約40本）。月約16円／本で業務用パレット定温保管の一般水準（月10〜20円／本）。個人向けセラー預かり（月100〜150円／本）とは別の料金帯 |
| 動産総合保険 | 平均在庫簿価の年0.15% | 全量付保。**滞留・破損ロスは保険でカバーするため費用計上しない** |
| 入庫・検品 | 320円／ロット | 出庫費用はチャネル別の変動販売費に含む |
| SPC維持費 | 年200万円 | 税務・事務受託・法務 |
| AUP | 年50万円 | 合意された手続の実施と報告書の発行 |
| 予備費 | 年50万円 | 想定外の実費に充当 |
| SPC人件費 | 年360万円 | SPC運営に係るWineBank側の実務人件費 |

### 現物譲渡マージン（`MARKUP`）

酒類販売業免許と取引口座の制約により、WineBankが調達した現物をSPCへ譲渡する必要がある。
独立企業間価格として1%を付加。SPCの取得原価は定価比50.0→50.5。払込5億に対し
実商品原価4.95億＋譲渡マージン500万円。

## 主要な結果（ニュートラル・上昇6%）

**在庫回転12ヶ月が主線。** 最短9ヶ月、延びても15〜18ヶ月を想定レンジとする。
回転12ヶ月には年間7.48億円の販売が必要で、現状の販売実力（5〜7億円）の上限をやや
上回る。この差は**SPC在庫の優先売却**（WineBank自己勘定在庫より先に売る）で埋める。

| 在庫回転期間 | 必要な年間販売額 | SPC税前利益 | エクイティ定常年間利回り | 年平均利回り（5年通算） |
| --- | --- | --- | --- | --- |
| 9ヶ月（最短） | 9.83億円 | 2.71億円 | 54.2% | 48.7% |
| **12ヶ月（主線）** | 7.48億円 | 2.10億円 | **42.0%** | 33.5% |
| 15ヶ月 | 6.07億円 | 1.73億円 | 34.7% | 25.8% |
| 18ヶ月 | 5.13億円 | 1.49億円 | 29.8% | 26.7% |

20%を割り込むのは**回転が30ヶ月を超えた場合**（ニュートラル）で、想定レンジの外。
ただし値引き5%と価格横ばいが重なるネガティブでは**回転15.9ヶ月**が分岐点となり、
想定レンジの中に入る。

費用を積み増しても利回りへの影響は小さい（AUP100万で▲0.10pt、大手監査300万でも
▲0.30pt）。**利回りを作るために費用を圧縮する必要はない。**

インポーターの仕入価格が上昇する局面では希望小売価格も連動して上昇するため、
定価比の構造（仕入50・売却70／80）は維持され、利回りへの影響は生じない。
