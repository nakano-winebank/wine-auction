# ワインファンド（SPC）組成提案 — 収益モデルと提案資料

実物ワインの流通価格差を収益源とするワインファンド（GK-TK）について、投資家リターンを
試算し提案資料を生成する一式。

## 2つの案

| | 倉持案 | 山本案（時価−α卸型） |
| --- | --- | --- |
| 資本構成 | エクイティ5億円のみ | WineBank現物出資60% ＋ 投資家出資40% |
| 募集総額 | 5億円 | 1stクローズ5億円 → 年度内2ndクローズ10億円 |
| SPCへの卸値 | 市中原価＋現物譲渡1%（50.50） | **時価 ×（1−α）＝ 59.38**（α＝20.8%） |
| WineBankの報酬 | 折半（成功報酬） | **卸す時点の値入れ ＋ 管理報酬 年2%** |
| 損益の配分 | 折半後に配分 | **出資比率どおり 60：40 のプロラタ** |
| **投資家利回り（定常年間）** | **21.0%** | **20.0%（1st）／20.3%（2nd）** |
| 20%の分岐点 | 回転12.7ヶ月 | 回転12.0ヶ月 |

山本案は2026年9月の協議を経て、WineBankの取り分を「出口の折半」から「SPCへ卸す時点の
値入れ」へ移した。**成功報酬（折半）は廃止している。**

## 実行

```bash
python3 model.py      # 単位経済・定常年間実力値・通算リターン
python3 structure.py  # 山本案（時価−α卸型）＋ figures.json 出力
python3 kuramochi.py  # 倉持案（エクイティ5億のみ）

npm install pptxgenjs docx
node build.js            # 山本案の提案資料（PPTX）※先に structure.py を実行すること
node changes.js          # 山本案の変更点資料（DOCX）※同上
node build_kuramochi.js  # 倉持案の提案資料（PPTX）
node annex.js            # 契約別紙ドラフト（DOCX）
```

**`build.js` と `changes.js` は `figures.json` を読む。** 数値を資料に手打ちしないための
構成なので、前提を変えたら必ず `python3 structure.py` を実行してから資料を生成すること。

## 山本案の構造（`structure.py`）

### 卸値の決め方 — これが新スキームの中心

```
時価（取得時点の加重平均売値）      定価比 75.00
α（時価からの控除率）              20.8%
SPC簿価 ＝ 時価 ×（1−α）           定価比 59.38　（市中原価50.00に対し ＋18.8%）
WineBankの値入れ                   定価比 9.38（簿価比 15.8%）
```

WineBankは**卸した時点で値入れを受け取る**。出口で取るのは管理報酬（総額の年2%）のみで、
**成功報酬（折半）は取らない。**

### 損益の配分

SPC税前利益を**出資比率どおり 60：40 でプロラタ配分**する。配分がプロラタであるため、

```
投資家利回り ＝ SPC税前利益 × 40% ÷（総額 × 40%）＝ SPC税前利益 ÷ 総額
```

となり、**出資比率そのものには依存しない。**

1stクローズ・回転12ヶ月・SPC税前利益1.00億円の内訳：

| | 金額 | 備考 |
| --- | --- | --- |
| 投資家（出資比率40%） | **40百万円** | 出資2億円に対し **20.0%** |
| WineBank（出資比率60%） | 60百万円 | 現物出資3億円に対する持分 |
| ＋ WineBankの値入れ | 75百万円 | 卸した時点で確定。SPCの費用には計上しない |
| ＋ 管理報酬 | 10百万円 | 総額の年2% |
| **WineBank受取合計** | **145百万円** | 持分60 ＋ 値入れ75 ＋ 管理報酬10 |

**WineBank受取145百万円のうち85百万円（約6割）は運用成果によらず確定する。**
成果に連動するのは持分60百万円のみ。前回（原価卸＋折半）は178百万円のうち163百万円が
成果連動だった。「投資家が儲からなければWineBankも儲からない」という説明はそのままでは
使えないので、資料では受取の内訳を明示している。

### ファンド設計

- ファーストクローズ5億円 → 年度内セカンドクローズ10億円、**運用期間5年**
- 出資金の95%をワイン購入に充当（現金5%）
- 中途解約は3年経過後、年度ごと。当初3年間はロックアップ
- 適格機関投資家等特例業務による私募。AUPを年次で実施
- 在庫配分は在庫比率によるプロラタを原則とし、プロラタで決し得ない部分はSPC優先
- 報告は四半期／年次：決算
- 仕入展開6ヶ月、ローリング運用、利益は複利再投資せず**年1回分配**
- 利回りは投資家の税引前ベース

### 単位経済（保有12ヶ月・定価100あたり・上昇6%）

| | 値 |
| --- | --- |
| 市中仕入原価 | 50.00 |
| 時価（取得時の売値） | 75.00 |
| **SPC簿価（時価−α）** | **59.38** |
| 売却時の売値（×1.060） | 79.50 |
| 変動販売費（6.44%） | ▲5.12 |
| 手取り | 74.38 |
| **単位粗利** | **15.00**（粗利率 18.9%） |
| 投下簿価利益率 | 25.3% |

## 主要な結果（ニュートラル・上昇6%・ファーストクローズ5億円）

| 在庫回転期間 | 必要な年間販売額 | SPC税前利益 | 投資家取分（40%） | 投資家利回り | 年平均利回り（5年通算） | WineBank受取 |
| --- | --- | --- | --- | --- | --- | --- |
| 9ヶ月（最短） | 8.36億円 | 1.28億円 | 51百万円 | 25.7% | 22.9% | 187百万円 |
| **12ヶ月（主線）** | **6.36億円** | 1.00億円 | 40百万円 | **20.0%** | 15.5% | 145百万円 |
| 15ヶ月 | 5.16億円 | 0.83億円 | 33百万円 | 16.6% | 11.8% | 120百万円 |
| 18ヶ月 | 4.37億円 | 0.72億円 | 29百万円 | 14.4% | 12.7% | 103百万円 |

セカンドクローズ（10億円）は回転12ヶ月で20.3%・5年通算15.8%、必要な年間販売額12.72億円、
WineBank受取292百万円。

**回転12ヶ月に必要な年間販売額は6.36億円で、現状の販売実力（年5〜7億円）の範囲内にある。**
卸値が上がったぶん同じ5億円で持てるワインが減るためで、前回（7.48億円）より条件は良い。
ただしセカンドクローズの12.72億円は実力を大きく超えるため、規模拡大は販売実力の拡大と
セットで判断する。

### 20%の分岐点

| 前提 | 20%を割る回転期間 | 主線12ヶ月からの余裕 |
| --- | --- | --- |
| ニュートラル（上昇6%） | **12.0ヶ月** | **なし** |
| 上昇0%（横ばい） | 8.6ヶ月 | 余裕なし（主線で13.3%） |
| 上昇10%（会社資料水準） | 16.5ヶ月 | ＋4.5ヶ月 |

**主線の回転12ヶ月がそのまま分岐点であり、余裕はない。** 回転12ヶ月の達成は20%確保の
必要条件。これが本ファンド最大の管理項目であることは前回から変わらない。

### 感応度（主線20.0%を基準・1stクローズ）

| 変動要因 | 変動幅 | 投資家利回り | 影響 |
| --- | --- | --- | --- |
| ワイン価格上昇率 | 年6% → 0% | 13.3% | ▲6.7pt |
| 在庫回転期間 | 12ヶ月 → 18ヶ月 | 14.4% | ▲5.6pt |
| 稼働率 | 95% → 85% | 17.6% | ▲2.4pt |
| B2Cのモール手数料 | 5.5% → 8.0% | 18.3% | ▲1.7pt |
| 卸値の控除率 α | 20.8% → 19.8% | 18.5% | ▲1.5pt |
| ワイン価格上昇率 | 年6% → 10% | 24.5% | ＋4.5pt |
| **【遮断】市中仕入価格** | 定価比 50 → 45 | **20.0%** | **±0.0pt** |
| **【遮断】売却価格** | 売値 ▲5% | **19.9%** | **▲0.1pt** |

**卸値が時価に連動するため、仕入価格と売値の変動は投資家利回りから遮断される。**
効く変数は「在庫回転期間」と「ワイン価格の上昇率」の2つに絞られた。

### 3シナリオ（ワイン価格上昇率別・投資家利回り）

| | 9ヶ月 | 12ヶ月 | 15ヶ月 | 18ヶ月 |
| --- | --- | --- | --- | --- |
| ポジティブ（年10%） | 30.1% | 24.5% | 21.2% | 19.0% |
| **ニュートラル（年6%）** | 25.7% | **20.0%** | 16.6% | 14.4% |
| ネガティブ（年0%） | 19.0% | 13.3% | 9.8% | 7.5% |

前回までは調達価格と売却価格でシナリオを定義していたが、卸値が時価連動になったことで
これらは投資家利回りに効かなくなった。そのまま用いると**ポジティブがニュートラルを
下回る逆転が生じる**ため、ワイン価格の上昇率で定義し直している。

## 山本案の変更の経緯（回転12ヶ月）

| | 前提 | 投資家利回り |
| --- | --- | --- |
| ① | 旧版：投資家5億円出資・折半・値上がり未計上 | 17.0% |
| ② | ワイン価格の年6%上昇を織り込む | 21.0% |
| ③ | デット2億円を導入し、出資を3億円に | 21.0% |
| ④ | デットを廃止し、WineBank現物出資60%へ | 21.4% |
| ⑤ | 管理報酬 年2% を新設 | 20.4% |
| ⑥ | **卸値を時価−αに、配分をプロラタに（折半を廃止）** | **20.0%** |

⑥では投資家利回りをほぼ同水準に保ったまま、報酬体系を「出口の折半」から「卸す時点の
値入れ」へ移した。なお**SPC簿価が50.50→59.38へ上がるため、同じ5億円で持てるワインは
定価換算で約15%少なくなる。** ファンドが生む付加価値そのものは年218百万円から年185百万円
へ約33百万円小さくなり、WineBankはその分を卸値で前取りしている。
