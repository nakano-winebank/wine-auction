# ワインファンド（SPC）組成提案 — 収益モデルと提案資料

投資枠5億円・運用期間5年のワインファンド（GK-TK）について、投資家リターンを試算し
提案資料を生成する一式。

> **倉持案は2026年8月のMTGで v2（直接所有・委託販売型）に全面変更された。**
> 以下の「2つの案」以降の記述は、山本案および倉持案 v1（SPC型・エクイティ5億）に
> 関するもの。倉持案の現行案は末尾の「倉持案 v2」を参照。

## 2つの案

同じ運用実態（総額5億円・回転12ヶ月）に対し、資本構成の異なる2案を用意している。

| | 倉持案 | 山本案 |
| --- | --- | --- |
| 資本構成 | エクイティ5億円のみ（デットなし） | デット2億円＋エクイティ3億円 |
| 投資家のリスク資本 | 5億円 | 3億円（別に貸付2億円） |
| 投資家の年間受取 | 105百万円 | 63百万円＋受取利息8百万円＝71百万円 |
| **投資家利回り（出資ベース）** | **21.0%** | **21.0%** |
| 投資家利回り（拠出5億ベース） | **21.0%** | 14.2% |
| WineBank取分 | 105百万円 | 139百万円（成功報酬63＋デット分76） |

**投資家利回りは出資ベースでは両案とも21.0%で完全に一致する。**

```
倉持案： 税前 × 50%          ÷ 5億 = 税前 ÷ 10億
山本案： 税前 × 3/5 × 50%    ÷ 3億 = 税前 ÷ 10億
```

分母と分子が同じ比率で縮むため、率としては同じになる。差が出るのは、同じ投資家が
5億円を拠出したときの合成利回り（倉持案21.0% / 山本案14.2%）。山本案では2億円が
金利4%固定・WineBank保証のデットとなるため、その分のリターンは下がるがリスクも
負わない。差額34百万円は、金利と保証責任を引き受けるWineBankの取分になる。

利回りの比率が同じであるため、回転期間別の利回り・3シナリオ・感応度・20%の分岐点
（回転12.7ヶ月）はすべて両案共通。異なるのは金額と資本構成の記述のみ。

## 提示指標について

**提案資料ではIRRを一切使わない。** 先方（資産管理会社）が用いている尺度が「想定利回り」
であるため、以下の2つに統一している。

- **投資家利回り（定常年間）** … 投資家の取分 ÷ 出資3億円
- **年平均利回り（5年通算）** … 運用期間中の累計分配額 ÷ 出資3億円 ÷ 5年

### 折半の定義（もっとも重要な前提）

**折半とは「投資家が得た利益をWineBankと折半する成功報酬」のこと。** SPC全体の利益を
50:50で割るという意味ではない。計算は次の2段階になる。

| 段階 | 計算 | 回転12ヶ月の金額 |
| --- | --- | --- |
| SPC税前利益 | 総額5億円の運用から生じる利益 | 210百万円 |
| ① 投資家帰属分 | × 出資3億円 ÷ 総額5億円 ＝ **5分の3** | 126百万円 |
| ② 投資家取分 | × **50%**（残り50%はWineBankの成功報酬） | 63百万円 |
| **投資家利回り** | 63百万円 ÷ 出資3億円 | **21.0%** |

したがって投資家の取り分は SPC税前利益の **30%**（＝ 3/5 × 50%）である。

WineBankは現金を拠出しないが、①成功報酬63百万円 と ②デット2億円に帰属する利益から
金利を控除した76百万円 の合計139百万円を受け取る。デット2億円はWineBankが金利4%と
保証責任を負う借入であり、投資家の出資とは切り離されている。期中の管理報酬（残高比例
フィー）は課さない。

### 粗利率と利回りの関係（混同しやすい点）

| | 値 | 分母 |
| --- | --- | --- |
| 単位粗利（定価100あたり・保有12ヶ月） | 23.88 | — |
| 粗利率（売上比） | 30.0% | 売却時の売値 79.50 |
| **投下原価利益率** | **47.3%** | **投下資本＝SPC取得原価 50.50** |

**利回りの源泉は投下原価利益率のほう。** 原価50.50で仕入れて手取り74.38で回収するため、
年1回転すれば投下資本が年47.3%増える。ここからSPC費用を引いて年間税前利益2.10億円、
うち5分の3の126百万円が出資3億円に帰属し、これを折半した63百万円が投資家の取分。
出資3億円で除して投資家利回り21.0%となる。

## モデルの前提

### 資本構成（`structure.py`）

総額5億円 ＝ **デット2億円（金利4%）＋ エクイティ3億円**。

- デット2億円の調達コストはWineBankが負担し、SPCの費用には計上しない
- SPC税前利益のうち出資3億円に帰属する分（5分の3）を投資家とWineBankで**折半**
- デット2億円に帰属する分（5分の2）は、金利と保証責任を負うWineBankが受け取る
- 投資家の元本3億円は満期に償還（デット2億円はSPC資産から返済）

回転12ヶ月・SPC税前利益2.10億円の内訳：

| | 金額 | 備考 |
| --- | --- | --- |
| 投資家帰属分（5分の3） | 126百万円 | |
| ├ 投資家 | **63百万円** | 出資3億円に対し **21.0%** |
| └ WineBank | 63百万円 | 成功報酬 |
| デット帰属分（5分の2） | 84百万円 | 金利8百万円控除後76百万円をWineBankが受領 |
| **WineBank合計** | **139百万円** | 成功報酬63 ＋ デット分76 |

### ファンド設計

- 総額5億円、**運用期間5年**
- **出資金の95%をワイン購入に充当（現金5%）**
- 中途解約は**3年経過後、年度ごと**。当初3年間はロックアップ
- 適格機関投資家等特例業務による私募。AUP（合意された手続）を年次で実施
- 在庫配分は在庫比率によるプロラタを原則とし、プロラタで決し得ない部分はSPC優先
- 報告は**四半期**（在庫明細・簿価・売上・試算表）／年次：決算
- 仕入展開6ヶ月、ローリング運用、利益は複利再投資せず半期分配
- 利回りは投資家の税引前ベース

### ワイン価格の上昇（`APPRECIATION`）

収益は二階建て。**フロー（流通価格差）＋ ストック（値上がり）** で構成される。

保有期間中に価格帯全体（希望小売・ネット最安・卸値）が連動して上昇するため、
取得原価は据え置きのまま売値だけが `(1+6%)^(保有月数/12)` 倍になる。

**値上がりの上乗せ幅は回転期間によらず年約4.0ポイントで一定**（出資3億円ベース）。
値上がりは在庫金額（ストック）に対して発生し、価格差は回転（フロー）に対して発生する
ため、両者は独立に足し合わさる。回転低下を「相殺」するのではなく、全体を「底上げ」する。

| 回転期間 | ① 価格差のみ（0%） | ② 値上がりの上乗せ | 投資家利回り |
| --- | --- | --- | --- |
| 9ヶ月 | 23.2% | +3.9pt | 27.1% |
| **12ヶ月（主線）** | 17.0% | +4.0pt | **21.0%** |
| 15ヶ月 | 13.3% | +4.0pt | 17.3% |
| 18ヶ月 | 10.9% | +4.0pt | 14.9% |

上昇率6%は、会社資料のFine Wine年率10%に対し保守的に置いたもの。ただし0%（横ばい）
だと主線でも17.0%となり20%を割る。**値上がりの織り込みは20%達成の前提条件**であり、
上乗せではない点に注意。

### 販売チャネル（`RATE_B2B` / `RATE_B2C`）

売値だけでなく手数料構造が異なるため、チャネルを分けて持たせている。

| | 売値（定価比） | 変動販売費 | 手取り |
| --- | --- | --- | --- |
| B2B 酒販店卸 | 70 | 1.0%（出庫・配送0.6％＋決済・与信0.4%） | 69.30 |
| B2C 自社EC・オークション | 80 | 11.2%（モール・出品5.5%＋カード決済3.2%＋出庫・梱包・クール便2.5%） | 71.04 |
| **加重平均（半々・主線）** | **75** | **6.44%** | **70.17** |

手数料が重くてもB2Cのほうが手取りは1.74高い。ただしB2Cは1本ずつの出荷で販売量に
上限があるため、回転期間を確保するにはB2Bの卸売が不可欠。

### 共通費用

| 項目 | 単価・料率 | 備考 |
| --- | --- | --- |
| 保管（定温倉庫） | 年7,500円／ロット | 1ロット＝定価100万円相当（約40本）。月約16円／本で業務用パレット定温保管の一般水準（月10〜20円／本）。個人向けセラー預かり（月100〜150円／本）とは別の料金帯 |
| 動産総合保険 | 平均在庫簿価の年0.15% | 全量付保。**滞留・破損ロスは保険でカバーするため費用計上しない** |
| 入庫・検品 | 320円／ロット | 出庫費用はチャネル別の変動販売費に含む |
| SPC維持費 | 年200万円 | 税務・事務受託・法務 |
| AUP | 年50万円 | 合意された手続の実施と報告書の発行 |
| 予備費 | 年50万円 | 想定外の実費に充当 |
| SPC人件費 | 年360万円 | SPC運営に係るWineBank側の実務人件費 |

### 現物譲渡マージン（`MARKUP`）

酒類販売業免許と取引口座の制約により、WineBankが調達した現物をSPCへ譲渡する必要がある。
独立企業間価格として1%を付加。SPCの取得原価は定価比50.0→50.5。払込5億に対し
実商品原価4.95億＋譲渡マージン500万円。

## 主要な結果（ニュートラル・上昇6%）

**在庫回転12ヶ月が主線。** 最短9ヶ月、延びても15〜18ヶ月を想定レンジとする。
回転12ヶ月には年間7.48億円の販売が必要で、現状の販売実力（5〜7億円）の上限をやや
上回る。この差は主として**組入銘柄の選定**（流動性の高い銘柄をSPCに入れる）で埋める。

| 在庫回転期間 | 必要な年間販売額 | SPC税前利益 | 投資家帰属分（5分の3） | 投資家取分（折半後） | 投資家利回り | 年平均利回り（5年通算） |
| --- | --- | --- | --- | --- | --- | --- |
| 9ヶ月（最短） | 9.83億円 | 2.71億円 | 163百万円 | 81百万円 | 27.1% | 24.3% |
| **12ヶ月（主線）** | 7.48億円 | 2.10億円 | 126百万円 | 63百万円 | **21.0%** | 16.7% |
| 15ヶ月 | 6.07億円 | 1.73億円 | 104百万円 | 52百万円 | 17.3% | 12.9% |
| 18ヶ月 | 5.13億円 | 1.49億円 | 89百万円 | 45百万円 | 14.9% | 13.3% |

### 20%の分岐点

| 前提 | 20%を割る回転期間 | 主線12ヶ月からの余裕 |
| --- | --- | --- |
| ニュートラル（上昇6%） | **12.7ヶ月** | **0.7ヶ月** |
| 上昇0%（横ばい） | 10.3ヶ月 | 余裕なし（主線で17.0%） |
| ネガティブ（値引き5%＋横ばい） | 8.5ヶ月 | 余裕なし（主線で13.7%） |

**回転12ヶ月の達成は「上振れ条件」ではなく20%確保の必要条件。** 余裕は0.7ヶ月しかない。
これが本ファンド最大の管理項目であり、組入銘柄を流動性上位に絞ることと、B2B卸とB2Cを
併走させて販売量を確保することが設計の中心になる。

### 感応度（主線21.0%を基準）

| 変動要因 | 変動幅 | 投資家利回り | 影響 |
| --- | --- | --- | --- |
| 在庫回転期間 | 12ヶ月 → 18ヶ月 | 14.9% | ▲6.1pt |
| ワイン価格上昇率 | 年6% → 0% | 17.0% | ▲4.0pt |
| 売却価格 | 売値 ▲5% | 17.5% | ▲3.5pt |
| 稼働率 | 95% → 85% | 18.7% | ▲2.3pt |
| B2Cのモール手数料 | 5.5% → 8.0% | 20.0% | ▲1.0pt |
| ワイン価格上昇率 | 年6% → 10% | 23.6% | ＋2.6pt |
| 調達構成 | 定価比 50 → 45 | 28.7% | ＋7.7pt |

費用を積み増しても利回りへの影響は小さい（AUP100万で▲0.10pt、大手監査300万でも
▲0.30pt）。**利回りを作るために費用を圧縮する必要はない。**

インポーターの仕入価格が上昇する局面では希望小売価格も連動して上昇するため、
定価比の構造（仕入50・売却70／80）は維持され、利回りへの影響は生じない。

## 以前の資料からの変更点（回転12ヶ月）

| | 前提 | 投資家利回り |
| --- | --- | --- |
| ① | 旧版：投資家5億円出資・折半・値上がり未計上 | 17.0% |
| ② | ワイン価格の年6%上昇を織り込む | 21.0% |
| ③ | デット2億円を導入し、出資を3億円に | 21.0% |

折半の定義は一貫して変更していない。デットの導入は投資家利回りを変えない（③）。
出資が5億円→3億円になる一方で投資家に帰属する利益も5分の3になるため、比率としては
同じ21.0%となる。デット2億円分の利益は、金利と保証責任を負うWineBankに帰属する。

# 倉持案 v2（直接所有・委託販売型）

2026年8月のMTGで、倉持案は資本構成の変更ではなくスキームそのものの入れ替えとなった。
試算は `kuramochi_direct.py`、資料は `build_kuramochi2.js` が担当する。
`model.py` は山本案と共有のため変更していない（価格前提と保管・保険・入庫の単価のみ流用）。

## v1 との違い

| | v1（SPC型） | v2（直接所有・委託販売型） |
| --- | --- | --- |
| 器 | 合同会社＋匿名組合（GK-TK） | 器を用いない。投資家が現物を直接所有 |
| 投資額 | エクイティ5億円 | **1億円**（単独投資家） |
| 投資家の立場 | 匿名組合員 | 現物の所有者 |
| 現物の譲渡 | SPCへ市中原価＋1% | 投資家へ市中原価＋**5%** |
| 販売 | SPCが売主 | **委託販売**。WineBankが自己の名で販売する問屋型の受託 |
| 顧客に対する売主 | SPC | **WineBank**。投資家は売買契約の当事者にならない |
| SPC関連費用 | 年660万円 | 発生しない |
| 利益配分 | SPC税前利益の折半（50:50） | **在庫回転期間に応じたティア** |
| 自己利用 | なし | WineBankの逸失利益を補償して現物を引き取れる |

## 費用の構成

| 区分 | 内容 |
| --- | --- |
| 固定経費 | 保管・保険・入庫。**拠出額1億円をフルにワイン現物へ充当した前提**で計上（年 約164万円） |
| 変動販売費 | 売上の **6.44%**（モール5.5%／カード決済3.2%／出庫・梱包2.5% をB2B/B2Cの構成比で加重。`model.py` 由来） |
| 人件費 | 売上の **7.5%**。WineBank側の実務人件費として別建て |

変動販売費と人件費の合計は **13.94%**。固定経費を含めた総費用率は在庫回転12ヶ月で15.02%。

## 利益配分ティア

配分率は個々の在庫の保有期間ではなく、**ポートフォリオ全体の在庫回転期間**で判定する。
投資家利回りはすべて**年率換算**（年間の投資家取分 ÷ 拠出額1億円）。

| 在庫回転期間 | WineBank | 投資家 |
| --- | --- | --- |
| 6ヶ月以内 | 70% | 30% |
| 9ヶ月以内 | 60% | 40% |
| **15ヶ月以内（主線12ヶ月はここ）** | **50%** | **50%** |
| 18ヶ月以内 | 40% | 60% |
| 24ヶ月以内 | 35% | 65% |
| 24ヶ月超 | 30% | 70% |

2026年8月のご指示により確定した水準（9ヶ月60% / 12ヶ月50% / 15ヶ月50% / 18ヶ月40%
/ 24ヶ月35% / 24ヶ月超30%。6ヶ月以内は70%で据置）。12ヶ月と15ヶ月が同率のため、
両者は「15ヶ月以内50%」の一段にまとめている。主線（回転12ヶ月）はこの段に属する。
段差は 10 / 10 / 10 / 5 / 5 ポイント。

### 先方のご要望との照合

- **最低10%** … 在庫回転 **34.1ヶ月**まで確保。主線12ヶ月で14.3%
- **20%は取り過ぎ** … 在庫回転 **4.6ヶ月**より速くならない限り超えない

## v1 から反転した点：回転リスクの所在

**v1では「回転12ヶ月の達成が20%確保の必要条件、余裕0.7ヶ月」が最大の管理項目だった。
v2では回転が延びても投資家利回りはほとんど下がらない。** ティア配分により投資家の
取り分比率が上がるため、12ヶ月11.5%に対し18ヶ月12.7%、24ヶ月12.2%と、むしろ上回る
区間がある。回転リスクはWineBank側の取り分（6ヶ月6,760万円→24ヶ月1,000万円）が吸収する。

**したがって「回転が速いほど投資家も得」という説明は成立しない。** 資料では
「回転リスクはWineBankが負担する」という書き方に統一している。

## 代わりに前提条件となったもの：ワイン価格の上昇

| 前提（在庫回転12ヶ月） | 投資家利回り（年率） |
| --- | --- |
| ニュートラル・上昇6%（主線） | **14.3%** |
| 上昇0%（横ばい） | 10.7%（在庫回転12.8ヶ月で10%割れ） |
| ネガティブ（値引き5%＋横ばい） | 7.6% ← 全域で10%割れ |

**値上がりが横ばいの場合、主線からの余裕は0.8ヶ月しかない。** 横ばい（0%）でも主線
12ヶ月なら10.7%を確保するが、10%を割るのは在庫回転12.8ヶ月。年6%の上昇を織り込む
ことで、この余裕が22.1ヶ月（10%割れは34.1ヶ月）まで広がる。**値上がりは上乗せではなく、
在庫回転の余裕を確保するための前提条件**と位置づけること。v1で「値上がりは20%達成の
前提条件」だった構図が形を変えて残っている。この点は資料に明記済みで、後退させないこと。

在庫回転の悪化そのものはティア配分が吸収する（主線14.3%に対し24ヶ月11.3%）。
吸収できないのは値引きによる粗利の毀損で、値引き5%＋横ばいでは全域で10%に届かない。
値引き販売の制限を契約上の防衛線とする。

## 自己利用（現物引き取り）

投資家はすでに取得原価（定価比52.50）を支払っている。委託販売に回していればWineBankが
得たはずの配分ぶんを逸失利益として補償し、現物を引き取る。補償額は通常の売却と同じ基準
（変動販売費・人件費を控除した後の利益に配分率を乗じたもの）で算定する。

平均定価25,000円／本の場合：

| 在庫回転期間 | WineBankへの補償 | 実質のお引き取り価格 | 同時点のネット最安値 | 差額 |
| --- | --- | --- | --- | --- |
| 6ヶ月 | 2,442円 | 15,567円 | 20,591円 | 5,024円安 |
| **12ヶ月** | **1,990円** | **15,115円** | 21,200円 | **6,085円安（28.7%引）** |

**長く保有するほど安く飲める**（WineBankの配分率が下がるため）。

## 未決の論点

1. **委託販売の建て付け** … 投資家側に酒類販売業免許を要しないことの確認。所轄税務署の
   酒類指導官および顧問弁護士の確認を、契約書ドラフト作成前に得る。問屋型（WineBankが
   自己の名で販売）であることが要件。代理型では投資家が販売主体になる
2. **自己利用の税務** … 法人所有資産を役員が私的利用する場合の役員給与認定リスク。
   先方の顧問税理士の確認が必要
3. **配分ティアの水準** … 2026年8月のご指示により 70/60/50/40/35/30 で確定。
   主線14.3%。優先配当（フロア）・上限（キャップ）を設けるかは投資家と協議中
4. **ティア境界の不連続** … 境界の前後で配分率が段階的に切り替わるため、境界直前に
   値引きしてでも売り切る動機がWineBank側に生じうる。値引き販売の制限を契約別紙で定める
   （先方了承のうえ、段階式のまま進める方針。最大段差は10ポイント）
5. **委託販売の建て付け（売主）** … 顧客に対する売主はWineBankとし、請求書発行・代金回収・
   クレーム対応・返品はWineBankが行う。貸倒れもWineBankが負担する（商法上、問屋は買主の
   履行を担保する責任を負う）。委託販売では税務上の売上が委託者に立つため、消費税の
   取扱いは先方顧問税理士の確認が必要

## 数値の出所

**資料の数値はハードコードしていない。** `kuramochi_direct.py` の `export_json()` が
`kuramochi_direct.json` を書き出し、`build_kuramochi2.js` がそれを読んで表・グラフを
組み立てる。前提を変えたらJSONを書き出し直せば資料側の数値もすべて追随する。

```bash
python3 -c "import kuramochi_direct as K; K.export_json()"
node build_kuramochi2.js
```
