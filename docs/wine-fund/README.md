# ワインファンド（SPC）組成提案 — 収益モデルと提案資料

投資枠5億円のワインファンド（GK-TK）について、投資家IRRを試算し提案資料を生成する一式。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `model.py` | 単位経済・定常年間実力値・月次キャッシュフロー／IRRの本体モデル |
| `sens.py` | 感応度分析、および8/5版からの改訂インパクトの要因分解 |
| `build.js` | 提案資料（PPTX）の生成スクリプト（pptxgenjs） |
| `WineBank_ワインファンドSPC組成提案_5億_20260811.pptx` | 生成物（全17枚） |

## 実行

```bash
python3 model.py      # 全シナリオの数値
python3 sens.py       # 感応度・改訂差分
npm install pptxgenjs && node build.js   # PPTX生成
```

## モデルの前提

- 投資枠5億円、稼働率85%（残15%は運転資金・解約準備として現金保有）
- 仕入展開6ヶ月、ローリング運用、利益は複利再投資せず半期分配
- 満期に在庫を売却清算のうえ元本償還。IRRは投資家の税引前ベース
- SPCの税前利益を投資家50：WineBank50で折半

### 2026/08/11 改訂で追加した前提

1. **SPC人件費 年360万円** — SPC運営に係るWineBank側の実務人件費を、GP取分ではなく
   SPCの固定費として計上（`SPC_PERSONNEL`）。SPC固定費は年800万→1,160万円。
2. **現物譲渡マージン 1%** — 酒類販売業免許と取引口座の制約により、WineBankが調達した
   現物をSPCへ譲渡する必要がある。独立企業間価格として1%を付加（`MARKUP`）。
   SPCの取得原価は定価比50.0→50.5。払込5億に対し実商品原価4.95億＋譲渡マージン500万円。

影響は定常利回りで合計▲1.0pt（1%譲渡▲0.61pt／人件費▲0.36pt）。

## 主要な結果（ニュートラル）

| 在庫回転期間 | 定常年間利回り | 投資家IRR（3年） |
| --- | --- | --- |
| 9ヶ月 | 23.1% | 16.9% |
| 12ヶ月（主線） | 16.9% | 11.0% |
| 15ヶ月 | 13.1% | 10.3% |
| 18ヶ月 | 10.7% | 5.1% |

リターンは粗利率ではなく在庫回転期間でほぼ決まる。改善の打ち手は「回転期間の短縮」と
「仕入価格の引き下げ」の2つに集約され、値引きによる販売促進は割に合わない。
