## 主要な結論

1. ビジョン借入は7.90億であり、「約6億」という前提とは1.9億の差がある
2. 「50.1%」＝ビジョン94,500株＋BOS 2,000株＝96,500株
3. ご提案のままでは資金使途18.97億に対し調達15.00億で3.97億不足
4. 正常化EBITDAベースではLBOローンの新規調達余力がほぼゼロ
5. 債権割引取得＋DES、現物出資、ビジョン再出資の組み合わせで③の所要額は2.1〜2.6億まで圧縮できる
6. 適正株式価値は現状水準で4〜5億、進行期織込みで10〜12億（5手法が収束）。20億はFY2028計画達成前提の値段
7. 出向費は月600万＝年0.72億（確定）。クロージング2027/11末ならFY2028に0.36億、FY2029以降0.72億の減益要因
8. ①15億ならDay1所要14.09億で②③満額15億に収まる。20億は16.60億で1.60億不足
9. 営業利益2億が報告ベースだとDSCR0.96倍で返済不能。報告ベース2.29億が最低ライン
10. ②を満額11億入れると15億評価で中野陣営31.5%。パートナー出資は7.83億が上限

## 基準確定版（base2oku.py）

2026年5月期の正常化営業利益を2.00億（出向費0.72億控除後）と確定した場合:

- 正常化EBITDA 2.65億、Net Debt/EBITDA 4.2倍
- 理論適正株式価値 4.73〜10.03億（EV/EBITDA 6〜8倍、中心7.38億）
- ①15億=9.9倍、①'20億=11.8倍
- みずほのタームローン上限 5.35億（DSCR1.2倍基準）→ 申込5.0億が妥当
- ①15億・パートナー6.37億・中野ファンド2.72億・TL5.0億 → 中野陣営55%、DSCR1.25倍
- 15億が適正になるのは正常化営業利益2.57億から、20億は3.20億から（8倍前提）
- 報告値1.58億から正常化2.00億への差額1.14億の説明資料が全ての前提

## 実行計画（plan_direct.py）

SPCを作らず直接投資。パートナーがビジョンから株式を買い、中野側が増資5億を引き受ける:

- 1株 7,485円（SO行使後）／MBO後の発行済 268,421株
- 中野邦人 74,000株 27.57%（既保有65,000＋SO行使9,000）
- 中野側（ファンド等）66,805株 24.89%（増資5.00億の引受）
  → **中野陣営 140,805株 52.46%**
- パートナー 96,500株 35.95%（ビジョン・BOSから7.22億で相対取得）
- 少数株主 31,116株 11.59%／ビジョンは持分ゼロ
- 純資産 △4.09億 → +0.91億（債務超過解消）
- 有利子負債 11.57億 → 6.57億。ビジョン借入は5億返済＋2.90億リファイで全額消滅
- Debt/EBITDA 2.5倍、DSCR 1.54倍（SPC案の1.20〜1.28倍から改善）
- ビジョン受取 15.12億（株式7.22＋借入返済7.90）全額現金・額面満額

## 実行計画B・自己株式取得（buyback.py）

Pre20億で15億増資し、5億でビジョン返済・10.02億で96,500株を自社株買い:

- 1株10,383円、新株144,462株、Post発行済337,078株、パートナー42.86%
- 中野氏の経済価値は 33.75%×20億=6.75億 → 27.02%×24.98億=6.75億 で不変
  一円も出資せずに支配権を取れるという着想は正しい

### 会社法上の関門3つ

1. **分配可能額**（461条）現状△8.94億。増資してもその他資本剰余金は増えないため
   依然マイナス。無償減資＋欠損填補（447・448・452条）でその他資本剰余金を
   10.89億まで積み上げて初めて10.02億の取得が可能。債権者保護手続で2〜3か月
2. **議決権**（308条2項）自己株式に議決権はないが、増資でパートナーが取得した
   42.86%は残る。普通株のままだと議決権は中野27.02%・パートナー60.05%で
   過半数を失う。**パートナーの15億を議決権制限付A種優先株にすることが必須**
   - A種完全無議決権 → 中野の議決権67.63%
   - A種に23.3%付与 → 中野50.10%／パートナー25.92%
3. **売主追加請求権**（160条3項）少数株主31,116株が請求すると追加3.23億。
   増資を18.2億にすれば吸収でき、少数株主のExit機会も同時に提供できる

### 直接投資案との比較

| | 直接投資 | 自己株式取得 |
|---|---|---|
| 中野の出資 | 5.00億 | 0円 |
| 中野の議決権 | 52.46% | 50.10〜67.63% |
| 中野の経済価値 | 13.10億 | 6.75億 |
| 所要期間 | 1〜2か月 | 3〜4か月 |

Pre20億はEV/EBITDA 11.8倍で理論適正(6〜8倍)の約2倍だが、増資では
Preが高いほど中野に有利なため、パートナーが飲むなら受けるべき

## 実行計画C・50:50イコールパートナー（equal5050.py）

中野氏以外の既存株主7社127,616株を全て20億評価で自己株式取得し、中野氏と
パートナーが議決権50:50となる構成:

- パートナー出資 － 中野ファンド出資 ＝ 常に6.75億（中野氏の既存65,000株の価値）
- ケースA（ビジョン借入5億返済）増資総額18.70億
  中野ファンド 5.98億(57,552株) ／ パートナー 12.73億(122,552株)
  発行済372,720株・議決権245,104株 → 中野陣営50.000%／パートナー50.000%
- ケースB（ビジョン借入7.90億全額返済）増資総額21.60億
  中野ファンド 7.43億(71,516株) ／ パートナー 14.18億(136,517株)
  発行済400,649株・議決権273,033株 → 50.000%／50.000%
- 分配可能額は両ケースとも充足（14.59億／17.49億 vs 買取13.25億）
- 設計上ちょうど50:50になるため議決権制限付種類株が不要。全て普通株式
- 少数株主が消え、売主追加請求権の問題も生じない
- 中野ファンドの必要額は Pre が低いほど軽い（15億→5.16億、25億→6.79億）

### リスク
1. デッドロック（50:50）— 株主間契約に解消条項が必須
2. 中野ファンドのガバナンス — 中野氏個人は26.5%のみ。GPへの議決権集約が絶対条件
3. エアトリの「20億超」希望との折衝
