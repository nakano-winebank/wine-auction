# あどばるMBO ファイナンス分析

みずほ銀行役員会食に向けた、株式会社あどばるMBOのデット／エクイティ調達設計。

| `su.py` | Sources & Uses のシナリオ比較 |

## 主要な結論

1. ビジョン借入は7.90億であり、「約6億」という前提とは1.9億の差がある
2. 「50.1%」＝ビジョン94,500株＋BOS 2,000株＝96,500株
3. ご提案のままでは資金使途18.97億に対し調達15.00億で3.97億不足
4. 正常化EBITDAベースではLBOローンの新規調達余力がほぼゼロ
5. 債権割引取得＋DES、現物出資、ビジョン再出資の組み合わせで③の所要額は2.1〜2.6億まで圧縮できる
6. 適正株式価値は現状水準で4〜5億、進行期織込みで10〜12億（5手法が収束）。20億はFY2028計画達成前提の値段
7. 出向費は月600万＝年0.72億（確定）。クロージング2027/11末ならFY2028に0.36億、FY2029以降0.72億の減益要因
8. ①15億ならDay1所要14.09億で②③満額15億に収まる。20億は16.60億で1.60億不足
9. 営業利益2億が報告ベースだとDSCR0.96倍で返済不能。報告ベース2.29億が最低ライン
10. ②を満額11億入れると15億評価で中野陣営31.5%。パートナー出資は7.83億が上限

## 基準確定版（base2oku.py）

2026年5月期の正常化営業利益を2.00億（出向費0.72億控除後）と確定した場合:

- 正常化EBITDA 2.65億、Net Debt/EBITDA 4.2倍
- 理論適正株式価値 4.73〜10.03億（EV/EBITDA 6〜8倍、中心7.38億）
- ①15億=9.9倍、①'20億=11.8倍
- みずほのタームローン上限 5.35億（DSCR1.2倍基準）→ 申込5.0億が妥当
- ①15億・パートナー6.37億・中野ファンド2.72億・TL5.0億 → 中野陣営55%、DSCR1.25倍
- 15億が適正になるのは正常化営業利益2.57億から、20億は3.20億から（8倍前提）
- 報告値1.58億から正常化2.00億への差額1.14億の説明資料が全ての前提

## 実行計画（plan_final.py）

第三者割当増資5億＋ビジョン借入5億返済を組み込み、SO 9,000株行使で中野陣営50.1%を確保:

- 純資産 △4.09億 → +0.91億（債務超過解消）。増資が担うためDESが不要になり税務リスクが消える
- 有利子負債 11.57億 → 8.61億。ビジョン借入は全額消滅（5億返済＋2.90億みずほリファイ）
- SO行使で中野の現物出資 5.06億 → 5.54億（行使価額1,000円前提）
- SPC出資: 中野5.54億(34.3%)・パートナー8.07億(49.9%)・中野ファンド2.56億(15.8%)
  → 中野陣営 50.1%
- SPCが必要とする現金は10.63億。②を11億以上集めても余る
- パートナー10億にすると経済持分38.1%。議決権50.1%維持には
  普通株6.14億以下＋議決権制限付優先株3.86億以上が必要
- 増資はSPC経由（ルートB）で。あどばる持分 SPC 88.41%／少数株主 11.59%
  パートナー直接引受だとSPCは63.52%まで低下
- LBOローンは2.04億でDSCR1.20倍（下限張り付き）。1.50億に抑えた
  DSCR1.28倍の推奨型を採用すべき
- ビジョン受取 15.12億（株式7.22＋借入返済7.90）全額現金・額面満額
