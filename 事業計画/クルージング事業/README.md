## 結論

**営業リターン（F&B・グループ4）: 参入すべき**
基本ケースで営業利益 4,428万円／年、税後 2,922万円。初期投資1,500万円に対しROI 295%、回収4.1か月。
損益分岐は「1運航あたりF&B売上12.3万円 かつ 年154回」。船舶リスクを負わないアセットライト構造。

**投資リターン（TK出資）: 現時点では保留**
TK①（造船）は税後IRR 14.2〜26.9%だが、按分定義とAM報酬が未開示のため上限値。
TK②（会員権発行）はIRR 30.4%に見えるが20年通算では1.40倍（年率2.0%）。未計上の年間維持費が1,600万円を超えるとゼロになる。

## 検証方法

Excelの全数式を LibreOffice で再計算（エラー0件）し、独立に組んだ Python モデルと全項目一致を確認。

## 最優先の確認事項

1. 年会費 年1.5億円（20年で30億円）の帰属 — 按分対象に含まれるか
2. 船舶4億円の第三者鑑定評価書 — 原価2億円からの100%マークアップの妥当性
3. AM報酬・組成費用のフィーテーブル — 契約23本分が全面未開示

WineBank として最初に詰めるべきは F&B業務委託契約（契約一覧19番）の3条項：
コーディネーションフィーの母数／最低乗船人数または最低保証額／クルーズ枠の長さ。
