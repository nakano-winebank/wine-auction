# 更新版ファイルを毎回添付する

ユーザーは「どこのファイルを見ればよいかわからない」ため、文書（特にベビーシッター業務委託契約書の .docx）を修正・更新したら、毎回次を行う。

1. 修正後のファイルをリポジトリ直下の作業ディレクトリに保存する（ファイル名は固定。例: `ベビーシッター業務委託契約書_修正版.docx`。バージョンごとに名前を変えず、同じファイルを上書きする）。
2. 必ず `SendUserFile` で更新版ファイルを添付する（`display: "attach"`、`status: "normal"`）。パスの案内だけで済ませない。
3. 返信の冒頭または末尾に、今回の変更点を箇条書きで短く示す（どの条の何を変えたか）。
4. 変更をコミットし、指定ブランチへプッシュする。PRはユーザーが求めた場合のみ作成する。

注意:
- 添付するのは最新版のみ。作業用の中間ファイルは送らない。
- 修正のたびに、変更していない条項は変えない。ユーザーが確定した条件（例: 第3条の延長報酬は月額に含む、第10条は原文のまま）を維持する。
