## 2. 手順
1. 各ファイルを Google Drive の `download_file_content` でxlsx（Googleスプレッドシートは exportMimeType に xlsx を指定）として取得し、scratchpad の専用フォルダに保存する。
2. 同梱の `find.py` で検索する：
   `python3 -I find.py '<銘柄の正規表現>' '<年の正規表現>' <xlsxファイル...>`
   - 銘柄は英語表記・カナ・半角カナの揺れを入れる（例：`'lafite|latour|ラフィット|ラトゥール|ﾗﾌｨｯﾄ|ﾗﾄｩｰﾙ'`、`'roman[eé]e[ -]conti|ロマネ'`）。
   - 年は4桁（`'1975'`）。「〜年代」は `'19[5-8][0-9]'` のように幅で探す。
3. 過去版・保険金額算定用・リネーム用のシートは参考扱い。**在庫ありと判断するのは最新の棚卸・在庫表シートだけ**にし、その基準日を必ず書く。
4. 見つからない場合は、近いヴィンテージ・同格の銘柄・同じ年の別銘柄を代替案として出す（生まれ年ギフトでは「同じ年」を優先）。

## 3. 回答のしかた
- 銘柄・ヴィンテージ・本数・所有会社・保管倉庫（SBS倉庫・寺田倉庫・舞浜など）・在庫表の基準日を表で示す。
- 社外向け（LINE・メール）の文面では**簿価は出さない**。価格を出すときは wine-market-valuation の時価ルール（楽天最安値、Wine-Searcher×1.2、オークション＋手数料16%）で算定し、「目安」と書く。
- 注意点として必ず書く：
  - 在庫表の基準日以降の売却やオークション出品は反映されていないので、川﨑さんにWineTechの現在在庫を確認してもらう。
  - 所有会社がP1・P2・スペースバンク等のときは、WineBankに戻すか、そのまま売るかの整理が要る。
  - 納期がある場合は、保管倉庫の出庫締めに間に合うか。
