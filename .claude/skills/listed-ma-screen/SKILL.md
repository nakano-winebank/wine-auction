# 上場企業 買収候補スクリーニング

非上場案件（`wine-ma-screen`）とは前提が全く違う。**株価の割安さより、
支配権を取れるかどうかが先に決まる。** その順番で絞る。

## 0. 着手前に固める3つの法務ゲート

スクリーニングより先。ここが通らない案件は候補に入れても意味がない。

1. **インサイダー取引規制（金商法166条・167条）**
   買収を助言する立場は「情報受領者」、公開買付が絡めば「公開買付者等関係者」。
   **案件着手と同時に売買禁止銘柄リストを作り、自社・役員・家族に回す。**
   候補リストを作った時点で、その全銘柄が対象になる。
2. **報酬を取る形の登録（金商法28条）**
   上場株式の売買の媒介・代理を業として行うと第一種金融商品取引業の登録が必要。
   財務助言も投資助言・代理業に触れる可能性がある。非上場M&Aの仲介と線が違う。
   登録済みの証券会社／FAと組むか、株式取得の媒介を行わない建て付けにするか。
   **必ず弁護士に当てる（顧問：神田総合法律事務所 五十里先生）。**
3. **開示義務（買主側）**
   5%超で大量保有報告（5営業日内）。重要提案行為目的なら特例報告は使えない。

## 1. 支配権のルート（2026年5月1日施行の改正を前提に）

| 取得比率 | 手段 | 制約 |
|---|---|---|
| 〜5% | 市場内・相対 | 開示不要 |
| 5%〜 | 同上 | 大量保有報告（5営業日内）。以後1%変動ごと |
| 〜30%未満 | 同上 | TOB義務なし |
| **30%以上** | **公開買付（TOB）が義務** | **2026/5/1施行で1/3→30%に引下げ。市場内取引（立会内）も対象に追加** |
| 2/3以上 | TOB | 全部勧誘・全部買付義務 |

**「流動性が高いから市場で買い集める」は30%で止まる。** 改正前は市場内取引が
3分の1ルールの対象外だったが、そこが塞がれた。必要資金は「30%分」ではなく
**TOB応募分＋α**で見る。

### 上場を維持したい買主の場合

非上場会社が上場会社と合併・株式交換・事業譲受を行い、東証が「実質的な存続会社は
当該上場会社でない」と判断すると、**新規上場審査基準に準じた審査を受けるための
猶予期間**に入る（合併等による実質的存続性喪失に係る上場廃止基準）。東証は
「軽微基準」を明示しており、それに収まらなければ詳細審査。
**上場を器として使う狙いなら、候補の条件そのものが変わる。**

### 買主が上場会社なら

**株式交換が使えるので現金が不要になる。** 資金力の制約が消えるため、
時価総額の帯を上に広げられる。買主のプロフィールを最初に確認すること。

## 2. 絞り込みの順番

この順でないと無駄が出る。2を先にやると候補が残らない。

1. **支配権が取れる株主構成か**
   - 筆頭株主が30%超 → 市場では無理。**オーナーと相対で交渉する案件**（下記3参照）
   - 筆頭株主10〜20%かつ持合いが薄い → 市場＋TOBのルートが成立
   - 親会社あり（○○ホールディングス傘下等） → 親会社との交渉案件
   - **創業家＋取引先持株会＋従業員持株会＋銀行・生保の合計**で見る。
     筆頭が10%でも合計40%なら固い
2. 市場区分・業種・時価総額の帯（買主の資金力から逆算）
3. **PBR 0.6倍以下。** 賃貸不動産があれば有報「賃貸等不動産の時価等の開示」から
   含み益を反映した**修正PBR**で見る
4. **ネットキャッシュ比率**（現預金＋有価証券−有利子負債）÷ 時価総額 ≧ 50%
5. 買収防衛策の有無（TDnetで「買収防衛策」を検索）
6. 売買代金20日平均・浮動株比率
7. 不祥事・係争（有報「事業等のリスク」、適時開示）
8. **既にアクティビストが入っていないか**（大量保有報告の重要提案行為の有無）
   → 入っていれば株価は反応済み。交渉相手も増える。**遅い**

## 3. 小型株では「筆頭株主が低い」を捨てたほうが速い

時価総額50億未満で上場を維持できている会社は、**たいていオーナーか親会社が
固めているからこそ残っている。** そうでない会社は市場再編と上場維持基準
（スタンダードは流通株式時価総額10億円以上）の経過措置終了でMBOか廃止になった。

つまり **「時価総額が小さい × 割安 × 筆頭株主が低い」はほぼ空集合。**

小型で探すなら、**「買収できる」を「市場で買い集められる」ではなく
「オーナーと相対で交渉できる」と読み替える。** オーナーが30〜50%持つ会社の
持分を相対で譲り受けるほうが速く、安く、確実。
30%超取得にはTOBが必要なので「オーナー持分を押さえた上でTOBで残りを取る」
という二段構えになる。

**この形の案件は、非上場M&Aと同じ仲介ルートで探せる**
（「上場オーナー企業の事業承継案件」として発注する）。

## 3.5 支配権ルートは3つ。買主プロフィールで決まる

「事業そのものが欲しい非上場の事業会社」が最も多い依頼者。その場合は下の②が本線。

| | ルート | 必要資金 | TOB義務 | 向く案件 |
|---|---|---|---|---|
| ① | **29.9%までの相対取得** | 時価総額×0.3 | **なし** | 支配権は不要。持分法・役員派遣・業務提携まで |
| ② | **オーナー持分の相対取得＋TOB＋スクイーズアウト** | 時価総額×1.35 ＋ 実務費用1〜2億 | あり | **事業が欲しい戦略買主。完全子会社化して上場廃止** |
| ③ | **第三者割当増資の引受で過半数** | 時価総額×0.9〜1.0 | **原則なし**（新株の引受けは既発行株券等の「買付け等」に当たらないため） | **会社側に資金ニーズがある案件** |

**②の時価総額の逆算**（TOBプレミアムは日本の中位30〜40%）:
`狙える時価総額 = (予算 − 実務費用1.5億) ÷ 1.35`
予算20億→約14億、40億→約28億、60億→**約43億**。

**③の重要な制約**（東証 企業行動規範）:
- 希薄化25%超 **または** 支配株主の異動 → 独立第三者の意見入手 **または** 株主総会決議
- 希薄化300%超は**原則禁止**（上場廃止もあり得る）
- 発行価額は取締役会決議前日株価の0.9倍以上（有利発行の回避／日証協指針）
- **資金は会社に入り、オーナーには入らない。** 引退・現金化したいオーナーには合わない

**③のTOB義務の非該当は確立した解釈だが、案件ごとに必ず弁護士に確認する。**

②で完全子会社化すると上場を失うが、**事業が目的なら上場維持コスト
（監査・IR・管理部門で年数千万〜1億）が消えるのでむしろプラス**。
上場を残したい理由がないか、依頼者に必ず確認する。

## 3.6 事業が欲しい買主の場合、許認可の人的要件が価格より先

**株式譲渡なら法人格が変わらないので許認可はそのまま承継される。**
事業譲渡・合併・分割の場合は建設業許可の事前認可が必要（2020年建設業法改正）。

建設業のチェック順:
1. **経営業務管理責任者** — 役員に5年以上の経営経験者が必要。オーナーが唯一の該当者なら、
   その人が抜けた瞬間に許可要件を満たさなくなる
2. **専任技術者** — 営業所ごとに常勤で配置
3. **特定建設業の財産的基礎** — 資本金2,000万円以上、自己資本4,000万円以上、
   欠損額が資本金の20%以内、流動比率75%以上。**買収スキームでこれを崩さない**
4. **監理技術者** — 元請で4,500万円以上（建築一式7,000万円以上）の工事に専任配置
5. **経営事項審査（経審）** — 完成工事高・自己資本額・利益額・技術職員数で決まる。
   オーナー交代では落ちないが、**技術者が辞めると等級が落ち、受注できる工事規模が落ちる**

不動産業: 宅地建物取引業免許は専任の宅地建物取引士（業務従事者5人に1人以上）。
株式譲渡なら免許は維持されるが役員変更の届出が必要。
不動産特定共同事業・賃貸住宅管理業は別許可。

## 4. 見た目は条件に合うのに使えないパターン

- **持合いが厚い。** 建設業に特に多い（取引先持株会＋銀行＋生保＋役員持株会）
- **従業員持株会＋役員持株会＋取引先持株会の三点セット** — 分散に見えて経営側の固い票
- **官公需依存** — 経営事項審査（経審）の点数は経営状況・技術職員数で決まる。
  オーナーや技術者が抜けると入札参加資格が落ちる
- **許認可の人的要件** — 建設業なら経営業務管理責任者・専任技術者、特定建設業なら
  財産的基礎要件。**オーナーが監理技術者を兼ねている中小ゼネコンは、
  その人が抜けた瞬間に許可が維持できない**
- **繰越欠損金狙いは効かない** — 株主等の持分50%超の変動＋事業の廃止等で
  法人税法57条の2の使用制限がかかる

## 5. データの取り方

3つの数字（PBR・大株主構成・流動性）を全部くれる無料の画面は存在しない。

- **大株主構成**: EDINET API v2 で有報を取得 → `MajorShareholdersTextBlock` を
  パース。`scripts/edinet_screen.py` がこれをやる（APIキーが必要・下記）
- **業種・市場区分**: JPX「東証上場銘柄一覧」（data_j.xls）
- **株価・時価総額・PBR**: 会社四季報オンライン／バフェット・コード／株探から手入力。
  候補100社なら30分
- **修正PBR**: 有報「賃貸等不動産の時価等の開示」

```bash
export EDINET_API_KEY=...     # https://api.edinet-fsa.go.jp で無料取得
python3 scripts/edinet_screen.py filings --from 2026-06-01 --to 2026-09-30 -o filings.csv
python3 scripts/edinet_screen.py holders --filings filings.csv -o holders.csv
python3 scripts/edinet_screen.py merge --holders holders.csv --jpx data_j.xls \
    --prices prices.csv --sector 建設業 --sector 不動産業 \
    --max-mcap 20000 --max-top1 25 -o candidates.csv
```

**注意：Claude Code on the web の環境では、組織のegressポリシーで
EDINET API・JPX・株探・みんかぶ・IRBANK・バフェット・コードがすべて
ブロックされる。このスクリプトはクライアント側の環境で回す。**

## 6. アウトプット形式

```
## 候補一覧（検証ステータス付き）
| 銘柄 | 市場/業種 | 時価総額 | PBR | 修正PBR | ネットキャッシュ比率 | 筆頭株主/比率 | 上位10合計 | 判定 | 検証 |

### 支配権ルートの判定（銘柄ごと）
- 市場＋TOB / オーナー相対 / 親会社交渉 / 不可

### 除外した銘柄とその理由
### 法務ゲートの状況（売買禁止リスト・登録・開示）
### 次アクション
```

**数字には必ず出所と基準日を付け、未検証は「未検証」と明記する。**
上場廃止・MBO・時価総額の変動は頻繁に起きる。記憶や古いデータで断定しない。
