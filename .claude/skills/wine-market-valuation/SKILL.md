# ワイン時価評価・売却価格算定（WineBank社内ルール）

社内で実際に使った計算式と判断基準をまとめたもの。新しく時価や売却価格を出すときは、まずこのルールに合わせ、外れる場合は理由を明記する。

## 1. 用語と価格の階層（必ず区別する）

| 用語 | 意味 | 例 |
|---|---|---|
| WB入値（原価） | WineBankの当初仕入原価（税抜）。インポーター仕入値・輸入原価 | P2ロットE：49,998,328円 |
| 卸単価（WB→Pn） | WineBankがファンド等へ売った価格＝そのファンドの取得原価 | P2ロットE請求書：70,986,900円 |
| 簿価（BS記帳額） | 決算書に計上された金額。卸単価と違う場合がある。**最優先で決算書から確認** | P2ロットE：60,000,000円（決算書の当期仕入から逆算） |
| 時価 | 下記2のルールで算定した市場価格（税抜で管理し、税込は×1.1） | |
| 採用価格 | 時価候補から最終的に使う価格（N列等） | |

- 金額は**税抜で計算して税込は最後に×1.1**。混在させない。
- 「原価」がWB入値なのか、ファンドの簿価なのかを毎回明記する（P2→P5の件で、WB入値基準だとP2で売却損になった）。

## 2. 時価の算定ルール

### 2-1. 基本（P5匿名組合契約 別紙2 第1条の考え方）
時価 ＝（①酒販店向け卸売価格 ＋ ②国内ECサイトの正規品最安値）÷ 2

- ①が取れない銘柄（バックヴィンテージ等）は、**② × 卸売価格/EC最安値の比率**を①とみなす。比率はWBの直近の卸実績（卸単価÷EC最安値）を集計して出す。②だけで時価を出すと、平均より約5%高くなり出資者に不利なため避ける。
- ①②どちらも取れない銘柄はファンドの取得対象外にする。
- 取得後にEC最安値が取れなくなった銘柄は、Liv-ex等の客観的な市場データで算定する。

### 2-2. EC最安値（楽天）の取り方
- 楽天の最安値（税込）と次点を取得し、税抜（÷1.1）に直す。取得元URLと取得日を残す。
- **除外ショップ**：中古品、シャトー・トーキョー、アルコワイン、FMJワインラヴズ、ガザン、SAKE PEOPLE、ファインワイン、VIOLET、ワインショップ ボルドー、リカル、JOYLAB、Whisky Bank、AXAS Co.
- **都度判断（他に無ければ参考値）**：勝田（＝ロマネ）、Fine and Rare、Selead
- 容量（375/750/1500ml）、セット品、セカンドワイン、ヴィンテージ違いを拾っていないか必ず確認する。

### 2-3. 楽天に無い場合の代替（優先順）
1. 同一銘柄の別ヴィンテージ価格 ×（1＋熟成調整率＋VTスコア調整率）。VTスコアはワインアドヴォケイト（WA）のヴィンテージチャート／個別評点を使う（カンテサンスの在庫表「PP」シートにもWA点の一覧あり）。
2. Wine-Searcher（海外）の中央値 × **1.2**（輸送費と消費税）。
3. TopLot等のオークション落札価格 ＋ **手数料16%**。
4. インポーター価格・生産者の公式ショップ価格（例：KENZO公式）。
5. 社内の既存時価。ただし「原価×0.947」のような**機械値**は時価として使わない（新基盤への移行当初の価格を拾った不具合。P1で43〜47行あった）。

## 3. 時価比較ファイルの検証チェックリスト（P1時価比較 v2〜v4.5 の指摘事項）

- [ ] 時価がちょうど「原価×一定率」になっていないか（例：×0.947 → 損益率−5.3%の行）
- [ ] 同じ金額が別の銘柄に並んでいないか（値の使い回し）
- [ ] 同じ生産者・同じ年で、特級が1級と同額など格付けと価格が逆転していないか
- [ ] 同じ銘柄の他ヴィンテージと比べて2倍以上離れていないか（例：DRC La Tâche 1996が2018年の約2.8倍）
- [ ] 容量違い、セット品、セカンドの価格を拾っていないか
- [ ] 原価側の異常（同一原価の使い回し、同一銘柄で原価が2つに割れているなど）
- [ ] 入値×本数と入値合計列が一致するか（例：P2ロットE Roty Charmes VV 47,500×6≠665,000）
- 指摘は色分けする：**赤＝誤りの可能性大**、**青＝要確認**。理由をセルのコメントかコメント列に書く。
- 結果は A：現行価格が正しい／B：修正済み／C：推定価格を算出し判断待ち／D：候補を並べて判断待ち に分けて報告する。
- 修正した場合の影響額（上方修正・下方修正の行数と金額、差し引き）を必ず出す。

## 4. 売却価格・損益の計算式

### 4-1. ファンド間売却（WB／Pn → P5等）
売却額（税抜）＝ 原価 ÷ 原価率

| 事例 | 原価の基準 | 原価率 | 結果 |
|---|---|---|---|
| WB→P5 川﨑さん選定分 | WB入値 | 82.6% | 税込1.5億（税抜1.3億） |
| P2ロットE→P5（戸髙さん案、2026/11） | WB入値 49,998,328 | 85% | 税抜58,821,562／税込64,703,718 |
| 参考：時価のみで評価した場合 | WB入値÷時価 | 69.9% | 原価率が低すぎるため85%程度に修正 |

- 「同じ計算式」と言われたら上の式（原価÷原価率）を同じ原価基準で当てはめる。原価基準が変わると結果が大きく変わるので確認する。
- 売り手の**簿価**と比べてキャピタルゲインを必ず出す。P2の件では85%案でP2に売却損（ロットE ▲1,178,438、ロットD ▲6,638,247）が出たが、中野さんの判断で許容。

### 4-2. 売却判断の目安（P1 DYM様向け消化仕入）
- 損益率 ＝（時価 − 簿価）÷ 簿価
- **+15%以上**で○（売却手数料10%を引いても5%残る）。理想は**+20%以上**（手数料を引いてネット10%）。
- 置きワイン価格 ＝ 採用価格 × 1.1（税込）

### 4-3. キャピタルゲイン管理列（必ず付ける）
購入時期／売却時期／売却先／売却本数／売却額（税抜）／売却対象簿価／キャピタルゲイン（売却額−簿価）／ステータス（確定・予定・候補）

## 5. BS・帳簿との照合
- ファンド別の商品残高は決算書の「期首棚卸＋当期仕入−売上原価＝期末棚卸」で必ず検算する。
- 請求書の金額と決算書の計上額が違う場合（例：P2ロットE 70,986,900 → 60,000,000）は決算書を正とし、差異を要確認事項に書く。
- 見積書xlsxの合計が請求額と合わない場合は、請求額と一致するシートを採用し、理由を書く（例：P2ロットD 702本37,399,500 vs 697本34,999,500）。

## 7. 出力の作法
- 推定値は「推定・目安」と明記し、リアルタイム価格ではないことを書く。
- 既存のファイルの数式・書式は壊さず、列を追加する形で直す。
- 個人名・借入条件を含むファイルは社外に出さない。
