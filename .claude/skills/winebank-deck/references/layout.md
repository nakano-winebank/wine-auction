## 表
- ヘッダ行 0.42〜0.56、データ行 0.38〜0.50
- `colW` の合計は必ず CW（12.06）ちょうどにする
- セル 10.5〜11.5pt。列が狭いと**ヘッダが2行に折り返して行高を押し広げる**
- 下端 = y + rowH総和。**この値を計算してから下の要素を配置する**

## よくある事故
1. 表に行を足して、下のカードが最終行を覆う → `tableEnd()` を計算する
2. カード本文が1行増えて下端を割る → 文章を削る
3. 見出しが2行に折り返して本文と重なる → 見出しを短くする
4. 配列インデックスのずれで暗い文字が暗い背景に出る → 位置を数え直す
5. `colW` の合計が CW と合わず表が右にはみ出す → 合計を検算する
