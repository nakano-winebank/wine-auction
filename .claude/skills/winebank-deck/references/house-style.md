# WineBank ハウススタイル（PowerPoint）

## 配色

ワインの会社なので、色は最初からこの一式に決まっている。案件ごとに選び直さない。
決め打ちにしておくと、複数の資料が同じ会社から出たものとして並んで見える。

| 役割 | Hex | 使いどころ |
|---|---|---|
| ボルドー（主役） | `8C2740` | 表紙・章扉の地色、強調、工事など最重要トラック |
| インク（文字） | `1B1A19` | 本文、見出し |
| グレー（副次） | `6E6866` | 注釈、出典、軸ラベル |
| 罫線 | `DCD7D2` | 表の罫線、グリッド線 |
| 淡地 | `F5F3F1` | 表のヘッダー行、カードの地 |
| 白 | `FFFFFF` | 本文スライドの地色 |

トラック／カテゴリを色分けするとき（ガント、凡例つきの表など）はこの5色を使う。
ボルドーを最重要トラックに当て、残りを順に振る。

| トラック色 | Hex |
|---|---|
| ネイビー | `2C4A6E` |
| ブラス | `9C6E28` |
| ボルドー | `8C2740` |
| セージ | `4E6B54` |
| プラム | `6B4A72` |

**避けること**

- 全面クリーム・ベージュ地（`F5F5DC` 系）。AIが作った資料に見える
- タイトル下のアクセント下線、スライド幅いっぱいのカラーバー、カードの片側だけの色帯
- 5色を等分に使うこと。ボルドーが主役で、他は支える側

## フォント

| 用途 | フォント | サイズ |
|---|---|---|
| 表紙タイトル | Yu Mincho（`Yu Mincho`） | 36–40pt |
| スライドタイトル | Yu Gothic Bold | 24–28pt |
| 小見出し | Yu Gothic Bold | 14–16pt |
| 本文 | Yu Gothic | 11–13pt |
| 表のセル | Yu Gothic | 9–11pt |
| 数字・日付・金額 | Arial | 本文と同サイズ、金額は Bold |
| 注釈・出典 | Yu Gothic | 8–9pt、グレー `6E6866` |

Yu Mincho は表紙と章扉のタイトルだけに使う。未インストールの環境では別の明朝体に
代替されるので、明朝であること自体は保たれて崩れない。本文まで明朝にすると
代替時の見え方が読めなくなるので、本文は必ず Yu Gothic。

数字を Arial にするのは、Yu Gothic の全角数字と半角数字が混ざったときに
桁が揃わないのを避けるため。金額・日付・パーセントは全部 Arial に寄せる。

## レイアウト

- キャンバスは `LAYOUT_WIDE`（13.33" × 7.5"）。`pres.layout` はスライドを追加する前に設定する
- 左右マージン 0.5"、上マージン 0.45"、下マージン 0.4"
- スライドタイトルは `x:0.5, y:0.4, w:12.33, h:0.6`
- タイトル直下に本文を置くときは `y:1.15` から
- ブロック間は 0.3"（詰めたいとき）か 0.5"（標準）。案件内で混ぜない
- 出典・脚注は `y:6.95`、8pt、グレー

## スライドのパターン

**表紙** — ボルドー地（`8C2740`）に白抜き。案件名を Yu Mincho で大きく、
その下に施設名・区画・日付。ロゴ代わりに `WINE BANK` を白の小文字間隔広めで置く。

**サマリー** — 上半分に結論を3行以内、下半分に確定事項を4〜6個のカード（淡地 `F5F3F1`）で並べる。
カードは「ラベル（8pt グレー）＋ 値（Arial Bold 大きめ）」の2段。日付や金額はここで効く。

**表** — ヘッダー行は淡地 `F5F3F1`、9pt、グレー文字。罫線は横線のみ `DCD7D2`。
縦罫線は引かない。確定事項の行だけボルドーの薄い地色を敷いて区別する。

**カード並べ（リスク・論点）** — 2列×3行まで。各カードに
カテゴリラベル（ボルドー 8pt）＋ 見出し（Bold 12pt）＋ 本文（10pt）。
枠線は `DCD7D2` の細線、地は白。影は付けない。

**章扉** — ボルドー地に白でフェーズ名と期間。工程表デッキでフェーズが変わる箇所に挟む。

**締め** — ボルドー地。次のアクションを3つまで、それぞれ期限つきで。

## 表紙・章扉のテキスト配置

濃色地のスライドでは文字を左寄せ・下寄りに置く。中央揃えにすると間延びする。
`x:0.9, y:2.6` あたりからタイトル、その下に副題、
右下（`x:9.5, y:6.6`）に日付と「株式会社WineBank」。
