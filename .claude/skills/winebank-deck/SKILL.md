# WineBank 提案書トンマナ

WineBankの資料は「静かで、余白があり、数字と固有名詞で語る」見た目に統一されている。会社紹介資料（2026年6月版）が基準で、そこから抽出した実測値をこのスキルに固定してある。色を目分量で決めたり、リッチな装飾を足したりすると、既存資料と並べた瞬間に別会社の資料に見えてしまうので、下の数値をそのまま使ってほしい。

## いちばん重要なこと

`scripts/wb-theme.js` に、キャンバス設定・パレット・共通部品（ロゴ、フッターバー、見出し、カード、強調バンド、統計タイル、表ヘッダー）が全部入っている。**毎回ゼロから書かずに、これを読み込んで使う。** 過去に同じヘルパーを何度も書き直して、そのたびに色や余白が微妙にずれた。

```bash
cd <作業ディレクトリ>
npm install pptxgenjs          # 未インストールなら
cp <skill>/scripts/wb-theme.js .
cp <skill>/assets/wine-bank-logo.png .
```

```js
const { init, slide, cover, card, band, stats, tableHeader, T } = require("./wb-theme");
const pres = init();                                  // 13.333 x 7.5 / 白背景
const s = slide(pres, "OVERVIEW", "提携全体像", "リード文はここに1行。");
card(pres, s, T.M, 1.60, 3.9, 2.0);                   // 標準カード
band(pres, s, 5.40, "この1枚で言いたいことを、ここに。");
pres.writeFile({ fileName: "out.pptx" });
```

各関数の引数は `wb-theme.js` の冒頭コメントに書いてある。既存資料の一部だけ直す場合はこのモジュールを使わず、後述の「既存pptxを編集する場合」を読む。

## パレット

| 用途 | 値 | 使いどころ |
| --- | --- | --- |
| 背景 | `FFFFFF` | 全ページ。クリーム・ベージュは使わない |
| 文字（主） | `1A1A1A` | 見出し・本文。純黒 `000000` は使わない |
| 文字（副） | `6E7378` | リード文、補足 |
| 文字（薄） | `A6ABAF` | 出典、ページ番号 |
| 濃紺 | `2F3941` | フッターバー、強調バンド、反転カード |
| **タン** | `C68A65` | アクセント①。線・チップ・数字 |
| タン（濃） | `B97246` | カードヘッダーの塗り |
| タン（淡） | `EFDCCE` | 濃紺の上に置く文字 |
| **ブルー** | `2E5495` | アクセント② |
| カード地（無彩） | `F6F6F6` | 標準のカード |
| カード地（暖） | `F3EFEC` | タン側のカード |
| カード地（寒） | `F0F4FA` | ブルー側のカード |
| 罫線 | `DDE0E2` | 表の罫線、白カードの枠 |

### 2つのアクセントの使い分け

これがWineBank資料の一番の特徴で、意味を持たせて使い分けている。混ぜると情報構造が壊れる。

- **タン `C68A65`** … 供給側・商業側。WineBank自身、テナント飲食店、商業施設、卸・仕入。
- **ブルー `2E5495`** … 利用者側。レジデンス居住者、ワーカー、個人会員。

「ヒルズ商業サイド ↔ ヒルズ利用者サイド」のように左右で対比させる図では、この2色で塗り分ける。片側だけの資料ならタン単色で通してよい。

## レイアウト

キャンバスは 13.333 × 7.5 インチ（16:9）。左右余白 `M = 0.62`。

```
0.32  ┤ セクションチップ（タン）            ロゴ（右上・幅1.36）
0.64  ┤ タイトル 23pt bold #1A1A1A
1.12  ┤ リード文 11.5pt #6E7378
1.52  ┤ ─── 本文ここから ───
      │
7.02  ┤ ─── 本文ここまで ───
7.20  ┤ ████ 濃紺フッターバー（高さ0.30・全幅）████
```

- フッターバーは**全ページ必須**。これがWineBank資料の識別子になっている。表紙にも入れる（ページ番号は省く）。
- `CONFIDENTIAL` を左下に 8.5pt `C7CACC`、ページ番号を右下に 10pt `A6ABAF`。どちらもバーの上。
- 文字サイズ：タイトル23／小見出し14〜16／本文10〜11.5／注記8.6〜9.2。数字の大見せは16〜26pt bold タン。
- 余白を詰めない。1枚に詰め込むより、Appendixに送る。

## 部品

- **セクションチップ** — タンの角丸に白の英字大文字（8.5pt bold）。`SUMMARY` `OVERVIEW` `POSITIONING` `SCHEME` `RISK` `THE FUTURE` `APPENDIX` のように短く。長い語（`EXECUTIVE SUMMARY`）は折り返して崩れるので12文字以内に収める。
- **PROGRAMタブ** — プログラム説明ページでは、チップの代わりに左上へタンのタブを置き、`PROGRAM` / `01` の2行にする。連番資料の現在位置がひと目で分かる。
- **カード** — 角丸半径0.05、塗りのみ、**影なし・枠線なし**が標準。白地に載せるときだけ `DDE0E2` の1px枠。
- **反転カード** — 濃紺地。見出しはタン淡 `EFDCCE`、本文は `DDE1E4`。1枚に1〜2個までにする。多いと重くなる。
- **強調バンド** — 全幅の濃紺帯（高さ0.44〜0.52）に中央揃えの白文字12.5〜15pt bold。そのページの結論を1文で置く。1枚に1本まで。
- **表** — ヘッダー行だけ濃紺で塗り、文字はタン淡。罫線は `DDE0E2` の0.75pt。pptxgenjsの`addTable`はヘッダーを塗れないので、表の上に濃紺の矩形とテキストを重ねる（`tableHeader()`がやってくれる）。
- **統計タイル** — 数字をタン16〜26pt bold、ラベルを9.5pt グレーで下に。4つ並べるのが基本形。

## フォント

`Yu Gothic` を和文・欧文とも既定にする。数字や英字ラベルだけ `Calibri` にすると締まる。**`Aptos` は使わない**（環境によって存在せず、代替フォントの字幅が違うため崩れる）。

## やらないこと

過去に一度作って却下された方向なので、繰り返さないように。

- **ボルドー×ゴールドの高級路線** — ワイン会社だからと深紅＋金にすると、会社紹介と完全に別物になる。
- **影・グラデーション・装飾ライン** — 全面フラット。見出し下のアクセント線も引かない（タイトル直下の短いタン線は表紙・締めページのみ）。
- **飾りの縦帯／カード端のストライプ** — 使わない。区別は塗りの濃淡で付ける。
- **1枚に同じ形のカードを4つ以上並べ続ける** — 全ページ同じ骨格になると機械的に見える。表・タイムライン・2:1の非対称構成を混ぜる。
- **円形の番号バッジを全ページに置く** — 手順やランキングなど、順序に意味があるページだけにする。

## 内容面の約束（提案書で毎回問題になる点）

見た目とは別に、WineBankの対外資料には決まった書き方がある。

- **投資・利回りの訴求は載せない。** ワインファンド、ワインST、エンジェル税制、Liv-ex指数、運用実績、IRRは対外提案書に入れない。「使えるサービス」として書く。投資家向け資料は例外。
- **WineBank CLUBの事実関係**（間違えやすいので毎回確認する）
  - 2025年7月開始の**月額**会員制。旧称 Fine Wine Collection。月会費8,800円〜のプラン制。
  - 中核特典は「レストランのワインが**飲食店仕入れ原価相当＝通常メニュー価格の約半額**」。一般の飲食店は卸原価の2〜3倍。
  - コルケージ（持込料）無料、**同伴者も同特典**。
  - 「グループ飲食店20%OFF」「年会費30万円」は**出資者特典・Founding 10の条件**でCLUBではない。混同しないこと。
- **数字には必ず時点と出典**を付ける（例：管理ワイン在庫30億円／2026年4月末時点）。試算値は「当社試算」と明記する。
- 競合は社名を出さず「ワイン専門小売・インポーター」と一般化する。

## 既存pptxを編集する場合

先方が手を入れたファイルを渡されたときは、**作り直さない**。デザインを壊すので、テキストだけ差し替える。

```python
from pptx import Presentation
prs = Presentation("in.pptx")
for slide in prs.slides:
    for sh in slide.shapes:
        if sh.has_text_frame:
            for p in sh.text_frame.paragraphs:
                for run in p.runs:            # run単位で置換すると書式が残る
                    run.text = run.text.replace("旧", "新")
prs.save("out.pptx")
```

`text_frame.text = "..."` は書式を壊すので使わない。表の中は `sh.table.rows[i].cells[j].text_frame` を同じように回す。グループ図形は `sh.shape_type == 6` で再帰する。末尾の不要スライドを消すときは `prs.slides._sldIdLst` から要素を外し、`prs.part.drop_rel(rId)` も呼ぶ。

## 仕上げの確認

LibreOffice で画像にして必ず目視する。和文フォントは代替されるため字幅が実物と多少違うので、文字が枠に接触していたら余裕を持たせる。

```bash
HOME=$PWD/.lo soffice --headless --norestore --convert-to pdf --outdir . deck.pptx
pdftoppm -jpeg -r 110 deck.pdf slide
```

見るべき順は、①枠からの文字あふれ、②要素の重なり、③カード下端との接触、④2アクセントの塗り分けが意味と合っているか、⑤フッターバーとロゴが全ページに入っているか。
