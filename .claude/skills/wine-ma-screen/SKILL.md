# WineBank M&A 即時スクリーニング

案件資料を受け取ってから **15分以内に「進む／指値して進む／見送る」の一次判断** を出すためのスキル。
DDではない。IMレベルの粗い情報で意思決定に足る材料を揃えることが目的。

## 0. 資料の所在

案件資料はチャットに添付されないことが多い。以下の順で探す。

1. Gmail: `mcp__Gmail__search_threads` → 仲介会社名・案件名・`has:attachment`。
   本文に価格目線・手数料・売主意向が書かれていることが多いので**本文を必ず読む**。
2. Google Drive: `mcp__Google_Drive__search_files` で `fullText contains '<社名>'`。
   案件ごとに `<社名>` フォルダ（IM・決算書・賃貸借契約書・基本合意書ドラフト）が切られている。
3. `read_file_content` でPDFのテキスト層を取る。**財務表が画像のIMが多い**ので、
   テキストに `5ヵ年計画` `財務諸表` などの見出しだけが出て数字が出ない場合は必ず画像で読む:
   ```
   pdftotext -f N -l N -layout in.pdf -   # 各ページの見出しを一覧化してページ特定
   pdftoppm -r 170 -png -f N -l N in.pdf out
   ```
   → 出力PNGを Read ツールで読む。10MB超のDriveファイルは `download_file_content` が
   使えないので、その旨を明示して先に進む（推測で数字を作らない）。

## 1. 拾う数字（これだけ）

| 項目 | 用途 |
|---|---|
| 純資産（直近期） | 価格上限の土台 |
| 営業利益（可能なら3期分） | 上限A・収益力トレンド |
| 減価償却費 | EBITDA・設備型かどうかの判定 |
| 現預金／有利子負債 | ネットデット、実質買収額 |
| 役員報酬・オーナー個人費用 | 正常収益力への調整 |
| 敷金・保証金／賃料 | 賃貸借の承継条件・退去リスク |
| 提示価格／仲介手数料 | 総投資額 |
| 従業員数・責任者の残留可否 | **必須条件**（下記） |
| ワイン（酒類）売上と構成比 | シナジーの分母 |

数字が取れない項目は「未入手」と書く。埋めない。

## 2. 価格上限の計算

```
上限A（収益型） = 純資産 + 営業利益 × 3年
上限B（設備型） = 純資産 + EBITDA × 4年
赤字事業        = 純資産以下
譲渡価格上限     = 10億円（案件単体）
総投資額        = 譲渡価格 + 仲介手数料 + 承継後の必要運転資金・改修費
```

`scripts/valuation.py` で計算する（レーマン方式の手数料込み）:

```bash
python3 scripts/valuation.py --net-assets 15122572 --op-income 6324025 \
  --depreciation 123142 --cash 42374969 --debt 27000000 --name 摩耶
```

判定は **総投資額 ≦ 上限** で見る。仲介手数料（最低150〜500万、レーマン5%〜）を
無視すると数千万円の案件では2割ずれる。過去の実際のやり取りでも
「御社の手数料含めて4000万程度であれば検討可能」と手数料込みで返している。

### 上限Bを使うときの注意（重要）

EBITDA×4は**設備が稼働資産として残っている場合のみ**有効。
`減価償却費 ≒ EBITDA`（＝営業利益がほぼゼロ）の案件でEBITDA×4を当てると、
償却という会計上の数字だけに4倍の値段を払うことになる。
この形の案件は必ず **維持更新capex（植替え・タンク・機械更新）を差し引いた
EBITDA − 維持capex** で再計算し、両方を併記する。

## 3. ワインシナジーの採点

各0〜2点、合計10点。6点未満はシナジーを理由にプレミアムを払わない。

1. **ワイン売上の伸びしろ** — 現状の酒類売上比率と客単価。高単価コース×ペアリングは2点。
2. **供給側の獲得** — 自社ブランド・ワイナリー・醸造免許・特区・畑など、仕入ではなく
   「造る側」に回れるか。
3. **在庫・与信の回転** — WineBankの在庫を出す先になるか（消化仕入契約が使えるか）。
4. **送客・体験** — オークション／EC／ワインセラー会員への体験提供の場になるか。
5. **人材・立地** — 責任者・ソムリエ人材が残るか、対象エリア内か
   （北海道・一都三県・京都・大阪・福岡）。

## 4. 必須条件（満たさなければシナジー点に関係なく見送り）

- **責任者＋社員の承継が必須**。オーナーが抜けて属人ノウハウが消える案件は対象外。
- 対象エリア外は原則見送り。
- スキーム（株式譲渡／事業譲渡）がIM内で矛盾している案件は、価格を語る前に仲介に確認。
  事業譲渡だと許認可（酒販免許・酒造免許・飲食店営業許可）と賃貸借が**引き継がれない**。

## 5. アウトプット形式

```
## <案件名> 一次判断: 進む / 指値して進む / 見送る

### 事実（出所つき）
- 数字は必ず出所（IM p.16 / 決算報告書65期 など）を添える

### 価格
- 上限A: X万円（純資産 + 営業利益×3）
- 上限B: Y万円（純資産 + EBITDA×4）※設備型のとき
- 提示: Z万円 / 手数料込み総投資額: W万円 → 判定

### メリット（3〜5個、シナジー点つき）
### デメリット・リスク（3〜5個、金額インパクトつき）
### ディールブレーカー（これが崩れたら降りる）
### 次アクション（誰に何を聞くか、期限つき）
```

**未入手の数字を推測で埋めない。** 「純資産が未開示なので上限が確定しない」ことが
一次判断のアウトプットとして正しい場合がある。そのときは仲介に投げる質問リストを出す。

詳細な社内基準・過去の判断事例は `references/criteria.md`。
