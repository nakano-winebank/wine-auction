# WineBank 買収基準（社内メモ）

出所: 2026-03-06 中野 → ウィット三宅宛「M&A希望案件」メール、および各仲介との実際のやり取り。

## 提示している希望条件（対外的にそのまま伝えている内容）

| 項目 | 条件 |
|---|---|
| 対象事業 | 酒販（蒸留所有）・レストラン・ベーカリー・ケータリング。**高価格帯もしくはワイン販売に繋がる事業** |
| 対象エリア | 北海道・一都三県・京都・大阪・福岡 |
| 価格目線 | 純資産＋営業利益3年以内。**赤字事業は純資産以下** |
| 譲渡価格上限 | 10億円以内 |
| 人員 | **責任者＋社員承継が必須** |

## 派生パターン

- **設備型（ワイナリー・蒸留所）**: 減価償却が重く営業利益が出にくいので
  純資産＋EBITDA4年分で見る。ただし維持更新capexを引いた後の数字も必ず併記。
- **部分取得＋再評価Exit**: 51%または66.7%を取得し、オーナーに引継ぎ・成長で協力してもらい、
  2〜3年後に同じ計算式で再評価して残り持分をExitしてもらう。単一業態・単一店舗で
  売主の価格目線が高いときの現実解（2023年ウィット案件で提示した建て付け）。
- **手数料込みで返す**: 「御社の手数料含めて4000万程度であれば検討可能」のように、
  仲介手数料を含んだ総額で価格目線を返すのが実務。

## 一次照会でいつも聞いていること

- ワイン（酒類）売上はいくらか、売上構成比は何%か
- 従業員は継続前提か、責任者は残るか
- 直近試算表（決算後〜直近月まで）
- 仲介手数料の金額・体系（レーマン方式か、最低報酬いくらか）
- グルメサイト評価（食べログ・ミシュラン）＝ワインが売れる客層かの代理指標

## 判断事例

| 案件 | 内容 | 判断 |
|---|---|---|
| 兵庫・ミシュラン1つ星 中華（M&A総研） | 売上9,300〜9,500万を3期維持、姫路城近く | 「手数料含め4000万程度なら検討可能」→ 乖離ありで一旦保留、後に売主が条件柔軟化 |
| 熊本 大型和食店（船井総研あがた） | 1店舗で売上2億超、客単価7,000円 | 「ワインが売れる店か」をグルメサイト評価とワイン売上で確認してから判断 |
| C&Bプラス（M&Aロイヤル） | 500万で内諾→親会社役員会で不成立 | 破談。以後「ワイン関連もしくは都心 or 北海道の割安飲食案件」に絞って案内を依頼 |
| 首都圏 不動産買取再販（M&Aロイヤル） | 100%株式譲渡 | 「社員残るなら興味あり」＝人員承継が前提条件であることの実例 |

## レーマン方式（IRI M&Aコンサルティングの例）

取引対価の額に応じた料率。実質売買金額ベース。

| 対価の額 | 料率 |
|---|---|
| 1億円以下 | 500万円（最低報酬） |
| 1億円超〜5億円以下の部分 | 5% |
| 5億円超〜10億円以下の部分 | 4% |
| 10億円超〜50億円以下の部分 | 3% |
| 50億円超の部分 | 2% |

仲介により最低報酬は150万〜500万とばらつく。**必ず個別に確認する**
（`scripts/valuation.py` の `--min-fee` で上書きできる）。

## 事業譲渡スキームの落とし穴

事業譲渡では以下が自動承継されない。株式譲渡との差は価格差以上に大きい。

- 酒類販売業免許・酒類製造免許（特区免許を含む）
- 飲食店営業許可
- 建物賃貸借契約（貸主の承諾が要る。IM上「譲渡後の賃貸条件は要相談」と書かれがち）
- 従業員の雇用契約（個別同意が必要）
- 繰越欠損金

IM内で「スキーム: 事業譲渡」なのに「譲渡対象: 株式100%」と書かれている資料が実在する。
矛盾は価格を語る前に潰す。
