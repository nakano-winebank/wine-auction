## 2. 卸し主（甲）保護のために特に入れた条項

- **第7条第2項**：グラス売り銘柄は「抜栓時に1本全量が販売されたものとみなす」。飲食店の消化仕入で最も揉めるのがグラス残量の扱いのため明記。
- **第7条第3項**：試飲・従業員教育・破損・棚卸不足はすべて販売扱い。回収漏れを防ぐ。
- **第8条第2項**：検収後の滅失・毀損リスクは店舗負担（資料の「在庫本数・滞留リスクは店舗管理」の考え方をB案にも適用）。
- **第9条**：分別管理・処分禁止・差押え時の通知協力。所有権留保を第三者に対抗するための実務上の要。
- **第12条**：6か月経過で自動的に「販売とみなす」構成にし、買取義務の履行を代金債権として明確化。延長は最長12か月・協議前置。
- **第14条第3項**：棚卸差異＝販売扱い。
- **第23条**：契約終了時の在庫は買取または引揚げ。

## 3. 締結前に必ず判断・確認すべき事項

1. **支払サイト「翌日払い」の実務負荷**
   販売のたびに振込を行う運用は店舗側の事務負担が大きく、交渉で必ず論点になります。第11条第3項に「週次締め」等への変更余地を残していますが、実運用としては**毎週締め・翌々営業日払い**を初期値に置くほうが締結しやすい可能性があります。方針をお決めください。

2. **保証金・与信**
   所有権は留保されるものの、在庫が店舗内にある以上、店舗倒産時の回収リスクは残ります。高額銘柄（オーパス・ワン等）を預ける場合、**保証金**または**代表者連帯保証**の条項追加を検討してください（現ドラフトには未挿入）。

3. **収益認識・税務**
   - 消化仕入は、甲側では販売報告時点で売上計上、乙側では同時点で仕入計上となります。日次で所有権移転が発生するため、**販売報告データの証憑性**（システムログの保存）を経理と詰めてください。
   - 消費税の適格請求書（インボイス）を、日次発生した取引についてどの単位で発行するか（都度／月次まとめ）を決める必要があります。第11条第5項は「法令に従い発行」とのみ記載しています。

4. **印紙税**
   本契約は継続的取引の基本契約書として**第7号文書（4,000円）**に該当する可能性が高いです。電子契約であれば課税されません。電子署名（クラウドサイン等）での締結を推奨します。

5. **独占禁止法・優越的地位の濫用**
   滞留在庫の買取義務は、条件次第で「不当な返品・押し付け販売」と評価されるリスクがあります。第12条は「乙の申出による延長」「甲による引揚げ選択」を残す構成にしていますが、**発注銘柄・数量の決定に店舗の意思が反映される運用**（＝甲が一方的に押し込まない）を実務で担保してください。第16条第5項に遵守条項を置いています。

6. **酒類免許**
   - 甲：酒類卸売業免許が必要（第16条第1項で表明）。
   - 乙：店内飲用のみなら飲食店営業許可で足りますが、**未開栓の持ち帰り販売を認めるなら酒類小売業免許が必須**（第16条第3項）。B案の運用でテイクアウトを想定するか、方針確認をお願いします。

7. **保管条件の現実性**
   第8条第1項の温度・湿度要件は、セラーを持たない店舗では満たせません。**セラー設備の有無を店舗ごとに確認**し、満たせない店舗には条件を緩和した別紙2を用意するか、B案の適用対象外とする運用を推奨します。

8. **A案（買取仕入れ型）との書式統一**
   A案（当月末締め・翌月末払い、リスクは店舗管理）は、本ドラフトから第7条・第9条・第12条・第14条を落とし、第11条を「納品日起点・当月末締め翌月末払い」に差し替えれば作成できます。ご要望があれば併せて作成します。
