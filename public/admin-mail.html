送信ドメインの設定手順

Resend の管理画面でドメインを追加すると、下記の種類のレコードが表示されます。 値は発行されたものをそのまま DNS に登録してください（下表の値は形式の例です）。

  1. Resend にログインし、Domains → Add Domain で送信に使うドメインを追加
  2. 表示された DNS レコードを、ドメインの DNS に登録
  3. Resend 側の状態が verified になるまで待つ（通常数分〜数時間）
  4. 本番環境に MEMBER_EMAIL_FROM と MEMBER_EMAIL_REPLY_TO を設定
  5. この画面でチェックがすべて緑になったら MEMBER_MAIL_BATCH=1 を設定
種類用途備考
MX / TXTSPFこの送信元からの送信を許可する宣言
TXTDKIM本文の改ざん検知に使う署名鍵
TXTDMARC任意だが推奨。なりすまし対策と到達率の改善

※ 既にオークションの通知メールを同じドメインで送っている場合、認証は済んでいる可能性があります。 上の事前チェックで確認できます。
