- **土台：** 戸髙さん「WineBank_5か年月次計画 v2.8」（11/26）のWineBank単体からカンテサンスを外したもの。

## 4. 戦略の変更点（カンテサンス案から）
1. **エクイティストーリー**
   - 旧：「三つ星を買う」
   - 新：「ブランド×ワインのバリューチェーンを自前で増やす」
     - 読む（ワイナート、読者約1,100人と広告主）
     - → 飲む（TM直営店、CLUB提携店）
     - → 持つ・預ける（セラー、私募ファンド、ワインマイル）
2. **ディールの構造**
   - LBO15億・SPC・アーンアウト・WineBankの連帯保証・12月末の決済期限が、すべてなくなる。
   - 調達は、3月末着金のVCラウンド1本に絞れる。
3. **調達額と資金使途**
   - 15億 → 5億（多くても7億）。
   - 使途：
     - TMの出店資金の不足分：統合モデル（10/10）で1.9億。プランBの想定では3.4億
     - 外部株主分の取得：0.3億
     - CLUB・ワイナートの立上げ
     - WineTech
4. **バリュエーション：** 1株57万円 → 48万円（前回45万円から＋7%）。
5. **関連当事者取引**
   - 中野からの取得には、中野を除く取締役会の承認と、第三者による株価算定が必要。
   - P3（WineBankが運営する匿名組合）の出資者の同意も必要。
   - 外部株主（1株15〜16万円で出資）の扱いを、今のうちに決めておく。
6. **月次計画（戸髙さん）**
   - v2.8の「カンテサンス」シートを「TM直営店」シートに置き換える。
     - 出店コホート別の月次
     - 単位：席数×席効率×回転×客単価
     - 家主の分割払い
   - 「連結」シートの持分按分（少数株主）は不要になる。
   - グループ経営指導料（80百万円・5社）にTM運営会社が含まれるかを確認する。含まれていれば社内取引として消去する。
7. **投資家ごとの訴求点**
   - ニッセイ（グルメ担当）：店舗のユニットエコノミクス。
   - 千島土地（大阪の地主）：2028年の大阪店の立地。
   - ジャフコ：規模。売上58億はカンテサンス案（48億）より大きい。

## 5. カンテサンスとTMの比較：属人性と将来性
| | カンテサンス（天才シェフ型） | TM日本（ブランド・業態型） |
|---|---|---|
| 規模 | 1店で売上約10億、営業利益5.6億（利益率約50%） | 1店で売上4.2億。9店で約34億（2031年度） |
| 利益率 | 極めて高い | 店舗EBITDA 15%、営業利益7〜10%、全社8% |
| 成長の源泉 | 単価とスイーツなどの新規事業。店を増やせない | 出店：年2店、標準店55坪・114席、投資回収3.8年 |
| 属人性 | **高い**：岸田シェフ＝三つ星。関与は3年間の契約のみ。後継者に代わると星を失うリスク | **低い**：標準化されたメニュー・業態・オペレーション。シェフ本人が厨房に立つ前提ではない |
| 残る依存 | 個人 | **ブランドのライセンス**（TBS社と2027年4月から5年、WineBankが締結済み） |
| 投資と借入 | 50億＋アーンアウト、LBO15億＋連帯保証 | 1店2.5〜3億（うち1.4億は家主の分割払い）、5年で累計23億、最大資金需要5.4億 |
| WineBankとのシナジー | 富裕層の顧客基盤（高単価・少量） | 1店で1日170人が来店：ワインの流通量、CLUB、マイルの使い先 |
| 主なリスク | 後継者、星の維持、借入 | 1号店が未開業、立地と出店の実行、人材、ライセンス更新 |

**将来性の見立て**
- **属人性の低さ**はVCやM&A買い手から評価されやすく、出店によって再現性のある成長を示せる。
  - 1号店の実績（2027/4開業）が出れば、評価が一段上がる。
  - 1号店の6〜12か月の実績が、次のラウンドやIPOの最大の論点になる。
- **TMが利益を出せる規模**（9店舗成熟時）：
  | ケース | 成熟1店の営業利益 | 店舗数 | 本部費 | 営業利益（年） |
  |---|---:|---:|---:|---:|
  | 基本 | 0.43億 | 9店 | ▲0.55億 | 約3.3億 |
  | 下振れ（席効率0.65・回転0.8、出店年1店） | 0.25億 | 5店 | ▲0.4億 | 約0.9億 |
  | 上振れ（直輸入ワイン・CLUB送客、12店） | 0.5億 | 12店 | ▲0.6億 | 約5.4億 |
- **最重要の交渉事項：ライセンス**
  - 「属人性が低い」は、ブランドを長く独占的に使えることが前提になる。
  - 今のライセンスは5年。日本での独占権、10年以上への延長、更新の条件を、DDの前に固めたい。
- **直営ならではの上積み**
  - ワイン：ワインは売上の約22%。WineBankの直輸入で原価率を5pt下げる。
  - マイル：直営店で使われたマイルの実質負担は料理原価分（約30%）で済む。提携店（90%補填）よりはるかに安い。
  - CLUB：直営店をCLUB会員の来店先にできる。
