## 前提（11/14版から変えた点）
- WineBank（2026/11/17〜）：Drive「261028_取締役会資料」の3か年予算 v16（FY26試算表1030版・プランE）の売上高・営業利益の合計だけを使う
  （売上高 12.0→14.4→18.0億円、営業利益 0.55→0.88→1.49億円）。事業別の内訳は作成中のため、資料には出さない。
  2029・2030年度は予算期間の伸び（売上高 年22.6%、営業利益 年+0.47億円）で延長した仮置き（スライドでは灰色、Excelでは青字）。
- 連結（WineBank＋カンテサンス）：売上高 22.6→48.0億円、営業利益 6.1→11.3億円（2026→2030年度）。
- カンテサンスの数字は11/14版と同じ。
- プレバリューは33億円（WineBank単体26.1億円＋カンテサンス持分6.9億円）を「目線」とし、ご相談できる形で示す。1株57万円。
- みずほ銀行の融資は総額15億円（LBOローン）のみ。3月末の残金15億円はエクイティ（WineBankの出資＋外部投資家様）。つなぎ融資は想定しない。
  みずほ銀行は、WineBank側が過半（51%）を持つスキームを承諾済み。融資の実行は、エクイティと同時、またはエクイティの確度を審査で確認できることが前提。
- 関連会社の合流は株式交換を想定（追加資金は不要）。交換比率は合流する時点の評価で決める。Excelの評価額14.1億円は現時点の参考値。
