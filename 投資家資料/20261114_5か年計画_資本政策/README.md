## 集計パターン
- ① グループ全体：WineBank＋カンテサンス＋アピシウス＋ブラッスリー（ティエリーマルクス）＋レストラン運営（従来の「含む」）
- ② WineBank＋カンテサンス：アピシウス以下（組織再編で集約する持分）を除く
- ③ 持分按分：①・②を各社の持分で按分（カンテサンスは調達後の64.1%（5億円）／77.1%（10億円）、アピシウス70%・TM66.7%・レストラン運営60%）

## 前提
- 年度＝WineBank決算期（10月〜翌9月）。2030年度＝2030/10〜2031/9。各社は月割りで組み替え。
- カンテサンスは榊原様提出（2026/11/12）の【B】新規事業込み＝IM計画＋新規事業（ガトー・オ・コンテ拡大・一品スイーツ店・ワインショップ／バー）。
- 2030年度への延長分（WineBank既存5%成長、ワインマイル4年目、TMの2032年3月期、アピシウス3%成長）は仮置き。
- レストラン運営はグループ各社をひとくくりにし（社名は非開示）、営業利益1億円で5年横ばい、持分60%で統一。
- プレバリュー：②＝WineBank単体25億円（前回ポスト26.1億円と同水準）＋カンテサンス持分7億円、①＝②＋組織再編で集約する持分14億円（アピシウス＝営業利益×6.2倍×70%＋純資産5.18億円×70%、TM＝11月増資の株価×66.7%、レストラン運営＝1億円×4倍×60%）。
  1株価格は②で決め（56万円、前回45万円の1.24倍）、①は集約する持分の対価として同じ株価で中野様に新株を発行する。
- 本ラウンドの調達額は5億円と10億円の2ケース。調達額の80%で、カンテサンス買収SPCの外部投資家の持分（出資15億円＝49%）を同じ条件で取得し、カンテサンス持分は51%→64.1%（5億円）／77.1%（10億円）になる。取得した分は外部投資家への年3%が不要になるため、その税引後額を純利益に加える。
- 調達額・充当率は「5か年計画」シートの青字を変えると、③と「資本政策」シートが再計算される（純利益は値で記載）。
