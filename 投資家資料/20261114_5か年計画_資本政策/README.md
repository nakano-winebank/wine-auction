## 集計パターン
- ① グループ全体：WineBank＋カンテサンス＋アピシウス＋ブラッスリー（ティエリーマルクス）＋レストラン運営（従来の「含む」）
- ② WineBank＋カンテサンス：アピシウス以下（組織再編で集約する持分）を除く
- ③ 持分按分：①・②を各社の持分で按分（カンテサンス51%・アピシウス70%・TM66.7%・バリューキッチン60%・その他70%）

## 前提
- 年度＝WineBank決算期（10月〜翌9月）。2030年度＝2030/10〜2031/9。各社は月割りで組み替え。
- カンテサンスは榊原様提出（2026/11/12）の【B】新規事業込み＝IM計画＋新規事業（ガトー・オ・コンテ拡大・一品スイーツ店・ワインショップ／バー）。
- 2030年度への延長分（WineBank既存5%成長、ワインマイル4年目、TMの2032年3月期、アピシウス・バリューキッチン3%成長）は仮置き。
- プレバリュー：②＝WineBank単体25億円（前回ポスト26.1億円と同水準）＋カンテサンス持分7億円、①＝②＋組織再編で集約する持分12億円。
  1株価格は②で決め（56万円、前回45万円の1.24倍）、①は集約する持分の対価として同じ株価で中野様に新株を発行する。
- 本ラウンドの調達額5億円は仮置き。Excelの「資本政策」シートのB列（青字）を変えると再計算される。
