# プランB：WineBank＋ティエリーマルクス（2026/11/25、社内検討用）

カンテサンス案件が見送りになった場合（11/25 ストライク礒田様メール）の代替案。

出店資金3.4億円を増資で入れて子会社化し、今回の増資を行う場合の試算と、プランA（WineBank＋カンテサンス）との比較。

## 前提
- 運営会社の株主は今回ラウンド完了時の想定：中野1,300株・WineBank P3 700株・外部投資家1,000株＝3,000株。
  実際は11/24時点で1,984株（中野1,300・P3 550・法人134）＋12/1池上様66株。外部の払込が少なければ、51%の株数と取得対価は下がる。
- 譲受価格は1株10万円（WineBank P3の出資価格：7,000万円÷700株）。直近の第三者割当は1株16万円。
- 51%の評価：直近株価で2.45億円、2031年の売却価値（EBITDA×5倍−家主分割残＋保証金−追加借入）を年25%・5年で割り戻すと2.0億円（ランレートで2.8億円）。
- プレ＝WineBank単体26.1億円＋51%の評価−取得対価1.53億円＝約27.0億円 → 1株47万円（27.2億円）。
- 増資後の持分：出店資金3.4億円を1株16万円で出資（2,125株）すると71%。
- 数値：WineBankは3か年予算v16（2029・2030年度は延長の仮置き）、ティエリーマルクスは2026/10/27投資家資料の5か年計画（FY4月〜3月を月割りで組替え）、プランAは `../20261115_シンプル版_WineBank＋カンテサンス/model_simple.json`。

## 要確認
- 中野からの譲受は関連当事者取引：取締役会承認（特別利害関係人を除く）と第三者の価格算定。
- 外部投資家のプレシード特例（エンジェル税制）への影響（WineBankが過半数を持つ場合）。
- TBS社とのブランド使用契約は全店共通でWineBankが締結済み（運営会社はサブライセンス）。子会社化に伴う契約上の手続き。
